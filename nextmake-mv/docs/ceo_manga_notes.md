## 1. あらすじ（エピソードごと）

### 第1話（ep1_01〜ep1_15）：富士山麓の研修所へ。「地獄の九十日間」の始まり
- **ep1_01**（カラー）：入社式の後、新卒者50名がそのままバスに乗り込みます。行き先は、毎年恒例の九十日間の「研修合宿」のための静岡県・富士山麓です。「ワクワクドキドキ新しい仲間たちとの『合同研修』が始まるー」
- **ep1_02**（カラー）：「はずだった・・・」。着いた先は、富士樹海に囲まれて周囲から孤立した研修所でした。出迎えた旅館のおばちゃんたちが暗い顔をしていて、ネクマックスは不思議に思います。
- **ep1_03**（カラー）：着いた瞬間、スーツ姿の先輩たちが豹変し「おいコラッ!! いつまで騒いどんじゃ!!」と怒鳴ります。ナレーションは「ネクマックスたちにとって地獄の九十日間が始まった」。
- **ep1_04**：「早くジャージに着替えてこい! 五分以内だ!」。時間がないので、ほぼトイレだけ済ませて集合場所の食堂へ向かいます。
- **ep1_05**：食堂には、バスにいた「怖い先輩達」3人がすでに待っています。奥に座っている2人は「おそらくボス達」です。
- **ep1_06〜ep1_07**：遅刻者が3人出て、頭を叩かれます。理由は「ト、トイレです、、」でしたが、「集合時間に間に合わないのであれば我慢しろ!!」と一喝されます。ネクマックスは心の中で「えげつないな。。。」。続いて整列と名前の呼び出しです。
- **ep1_08**：カイ、タマ、ソネ、グッチ、ナラ、イグーチ、ネクマックスの順に呼ばれます。「声が小さいぞ! もっと腹から声を出して返事しろ!」
- **ep1_09〜ep1_10**：呼ばれた者同士が同じチームになり、部屋も「衣食住全て一緒」です。遅刻者が一人でも出たら「チームの連帯責任とするから覚えておけ! 全ての事でだ!」と告げられます。
- **ep1_11**：声を出していなかった者のいるチームに「連帯責任だ!! 腕立て十回!」。
- **ep1_12〜ep1_13**：腕立てをしているチーム以外は部屋（ドアの番号は「503」）に戻れます。チームで自己紹介をし合い、ネクマックスは「大阪から来たんだ」、ソネは「沖縄から来たんだ!」と言い、ナラとイグーチも名乗ります。
- **ep1_14〜ep1_15**：「何が起こってるのか分からないくらい戸惑っているんだ」「社会人ってこんなに厳しいのかな・・」「まさかのまだ合宿一日目なのかよ!」と言い合って就寝します。

### 第2話（ep2_01〜ep2_09）：「まるで軍隊」の合宿と、1年前の就活の回想
- **ep2_01〜ep2_02**：翌朝から「地獄の連帯責任ゲーム」が始まります。湖に向かって一人ずつ「社会人の意気込み」を叫ぶよう命じられ、ネクマックスが最初に指名されます。「ロボコン大学のネクマックスと申します! 今日から頑張ります!」と叫ぶと、先輩が「何を頑張るんや! もっと具体的に言え!! ふざけとったら連帯責任やぞ!!」と怒鳴り、何かを投げつけます（靴のようにも見えますが判別できません）。ネクマックスの心の声は「まるで軍隊だ!」。
- **ep2_03**：毎朝の長距離ランニング競争があり、負けたチームは一日正座や一日両手にバケツをさせられます。「竹刀で強打されることもあった」。次第にチームの仲が悪くなって仲間割れし、「心身共に地獄の日々だった」。ページの最後で、ネクマックスが「こんなはずじゃなかった。。」と振り返ります。
- **ep2_04**（回想開始）：「一年前」。大学4年生のネクマックスは就活の真っ最中でした。茶髪で面接に行き、面接官は心の中で「こいつは何で茶髪やねん」「論外やな」。
- **ep2_05**：結果は不採用（「ご縁がなかったか」）。ナレーションは「怠け者だったネクマックス」とし、寝坊して「もう大遅刻だ! けど行くしかない!」と走る場面が続きます。
- **ep2_06**：遅刻して入室し、面接担当者は「あの遅刻茶髪野郎は無しだな」。「もちろん」結果は不採用です。ネクマックスは「とりあえず髪は直そうか」と決め、「このヘアスタイルともおさらばかぁ」「ショックだなぁ。。」。
- **ep2_07**：翌日、大学で友人たちが「初めて見る! ノーマルバージョン!」「似合わないね」と騒ぎます。入学時から茶髪だったからです。ここから就活は一気に進み、「やはり原因は髪の毛だった」「分かっていたことだが（笑）」。
- **ep2_08**：その後、4社ほどの選考が一気に並行して進みます（二次面接の案内が届く）。「そしてついに春は訪れる」。最終面接の相手は専務で、「会社のナンバー2の方だった」。ネクマックスは「素敵な方だな」と感じます。
- **ep2_09**：専務は「現場を大切にする方」で、この日も就活生と話したくて、たまたま面接を担当していました。「温かい人柄、会社、社会を良くしていきたいというビジョンに共感した」「ここまで強く共感したことは人生で初めてだった」「この方の下で働きたいと思った」。「そして後日ついにー」

### 第3話（ep3_01〜ep3_06）：内定、代表スピーチ、そして暗転
- **ep3_01**：「採用」。入社式での新入社員代表スピーチも頼まれます（「代表でスピーチか。大役をいただけて感謝だな」）。「僕にもついに春が訪れた!」。そして翌年の4月になります。
- **ep3_02**：「新社会人生活がスタートする!」。「あの専務のような人間に俺はなりたい」。入社式の直後が研修合宿だと知り、「初っ端から最高のスタートを切るぞ!」。
- **ep3_03**：入社式は「一流ホテルの一室を貸し切っての入社式」でした。ネクマックスは「スーツはまだ着慣れないな 気も引き締まるぜ」。
- **ep3_04**：専務も出席しています。厳かな雰囲気の中で、ネクマックスが代表スピーチをします（「一人でも多くの方を幸せにできるようー」）。
- **ep3_05**：同期たちから大絶賛され、「嬉しかった!」。余韻に浸る間もなくバスに乗り、「これから九〇日間の研修合宿が始まる!」「わくわく!」。ここで第1話冒頭につながります。
- **ep3_06**：見送る専務に心の中で「僕はあなたみたいになるぞ!」「研修合宿も頑張るぞ!」。直後のコマで「こんなはずじゃなかった。。」と現在に戻ります。

### 第4話（ep4_01〜ep4_06）：逃げられない三ヶ月、「スポーツ大会」の宣告
- **ep4_01**：「最初、期待を胸に語り合っていた仲間同士の激しい喧嘩」が起き、連帯責任の恐ろしさを感じる「心身共に地獄の日々」が続きます。研修の構成も説明されます（「その後の三十日間は東京と福岡に分かれて研修」「そしてまた三十日間富士山麓に戻っての研修」）。
- **ep4_02**：「実は一年前逃げ出した先輩が富士樹海に吸い込まれ行方不明に。という事実を知った」（警察犬による捜索が描かれています）。ネクマックスが「悪夢だな」と言うと、ソネが「悪夢ならまだマシだよ」「夢なら覚めるじゃないか。これは現実だよ。寝てる時だけだよ、楽で居られるのは。」と答えます。
- **ep4_03**：「みんな逃げたくても逃げられない まるで生きるか死ぬかの三ヶ月。」。はちまき姿の先輩が「今日はスポーツ大会だ!!」と告げます。
- **ep4_04〜ep4_06**：ルールは、25mの線の間を往復（50m）して、上位5位に入れば抜けられるというものです。入れなければ「永遠に走り続けることになる!!」（「まさに終わりなきシャトルラン」）。インターバルは短く、「最後まで残ったやつがいるチームは罰ゲームだからな!!」とここでも連帯責任です。ネクマックスは「絶対真っ先に五位以内に入ってやる!」。

### 第5話（ep5_01〜ep5_06）：シャトルランで自分の限界を知り、ひらめく
- **ep5_01〜ep5_02**：「よーい、どん!!」。ネクマックスは「どうだ俺のクイックターン!!」と張り切りますが、周りが速く（「早っ!!」）、「ちくしょう! 五位以内に入れなかった」。
- **ep5_03**：すぐに2回目が始まり、「想像以上にキツイ!!」。
- **ep5_04〜ep5_05**：体力はすぐに底をつきます。後で分かったことですが、新入生の中にはマラソンの国体選手やバスケットのインターハイ出場選手がいました（「そんな人たちに勝てるわけがなかった」）。ネクマックスは「そこまでスポーツをしてこなかった俺にとってはー」「この種目は相当不利だ」と考えたあと、「ん? 待てよ、」。
- **ep5_06**：「残っている他の皆んなも辛いのは変わらないはず、、だよな、、」。周りのうめき声（「きちぃ、、、」「体力配分を考えないと最後まで持たないな、、」）を聞いて、「そうか! 分かったぞ!」。**何に気づいたかは明かされないまま、ここで終わります（続きは次回以降）。**

## 2. 本人の人生の事実として読み取れること

凡例：**［明示］**＝ページに書かれていること／**［示唆］**＝描写から推測できるが書かれてはいないこと。
いずれも「マンガの中でネクマックスについて描かれていること」です。実際の出来事かどうかは本人への確認が必要です。

- ［明示］スポーツはそこまでしてこなかった（ep5_05「そこまでスポーツをしてこなかった俺にとってはー」）。

### 入社時の出来事

- ［明示］スピーチの中の一句として「一人でも多くの方を幸せにできるようー」が描かれている（ep3_04）。スピーチの全文はありません。

### 「暗黒」の中身：社会人デビュー直後の研修合宿
以下はすべて［明示］です。
- 場所は富士樹海に囲まれた孤立した研修所で、期間は九十日間（ep1_01〜02）。
- 先輩たちが豹変し、「5分以内に着替え」などの時間的な圧力をかける（ep1_03〜04）。
- 遅刻者は頭を叩かれる。トイレで遅れても「我慢しろ」（ep1_06〜07）。
- チームは衣食住全て一緒で、「全ての事で」連帯責任。腕立て十回などの罰がある（ep1_09〜11）。
- 湖に向かって「社会人の意気込み」を叫ばされ、否定され、物を投げつけられる（ep2_01〜02）。
- 毎朝の長距離ランニング競争。負けたチームは一日正座や両手にバケツ。「竹刀で強打されることもあった」（ep2_03）。
- 仲間割れと喧嘩が起き、「心身共に地獄の日々」「まるで生きるか死ぬかの三ヶ月」（ep2_03、ep4_01、ep4_03）。
- 研修の内訳：「その後の三十日間は東京と福岡に分かれて研修」「そしてまた三十日間富士山麓に戻っての研修」（ep4_01）。
  - ［示唆］ep1_14の「これが先ずは一カ月続くのかな」と合わせると、富士山麓30日＋東京・福岡30日＋富士山麓30日で計90日と読めます。ただ、ep4_01の直前にある「これが三ヶ月間続き」という一文とのつながりが曖昧です（6章参照）。
- 一年前に逃げ出した先輩が富士樹海で行方不明になった、と「事実を知った」（ep4_02）。**マンガ内では「事実」とされていますが、噂や誇張の可能性もあり検証できません。** 映像で扱う場合は特に注意が必要です。
- 「スポーツ大会」は終わりのないシャトルラン形式で、最後まで残った者のいるチームは罰ゲーム（ep4_03〜ep5_06）。

### 転機
- ［明示］髪を直したことで就活が好転した（ep2_07）。
- ［明示］専務との出会い。「人生で初めて」の強い共感で入社を決めた（ep2_09）。
- ［明示］期待から暗転する。「こんなはずじゃなかった。。」（ep2_03、ep3_06）。
- ［明示］シャトルランの最中に何かを悟る（「そうか! 分かったぞ!」ep5_06）。**中身は明かされていません。**

### 夢、そして起業との関係
- ［明示］はっきり書かれた目標は「あの専務のような人間になりたい」です（ep3_02、ep3_06）。
- ［明示］スピーチの一句は「一人でも多くの方を幸せにできるようー」です（ep3_04）。
- ［示唆］タイトルは「夢を信じたネクマックス」ですが、この5話では「夢」の具体的な中身は語られません。作中で「夢」という言葉が出るのは、ep4_02のソネの「悪夢ならまだマシ」「夢なら覚めるじゃないか。これは現実だよ」だけです。
- **起業の動機や経緯は、この5話（①）には一切出てきません。** 専務が掲げた「社会を良くしていきたい」というビジョンや、スピーチの「一人でも多くの方を幸せに」が後の起業につながる伏線にも見えますが、あくまで推測です。

### 読み方の注意
- このマンガは、ロボットのキャラクター、架空の固有名詞、効果音やギャグ的な演出（「（笑）」、はちまきの先輩など）を使った**脚色されたコメディ調の自伝**です。人数、日数、体罰、行方不明の話などを映像で「事実」として紹介する場合は、本人か会社に事実確認をしてください。
- 前の職場は名前が出ていませんが、体罰や人の失踪を思わせる描写があります。特定につながる表現は避けるのが無難です。

## 4. テーマ

1. **期待と現実のギャップ**：「はずだった・・・」（ep1_02）と「こんなはずじゃなかった。。」（ep2_03、ep3_06）が何度も繰り返され、希望に満ちた入社が一気に暗転します。
2. **ロールモデルとの出会い**：現場を大切にし、温かい人柄で、社会を良くするビジョンを持つ専務です。「この方の下で働きたい」「あなたみたいになる」。この5話で最もポジティブな軸です。
3. **人を幸せにする**：代表スピーチの「一人でも多くの方を幸せにできるようー」。
4. **連帯責任、チーム、仲間**：衣食住全て一緒で、罰は連帯責任です。そのために仲間割れや喧嘩が起きる一方、同室の仲間と「俺たちも一緒だよ」と声を掛け合う場面もあります（ep1_14）。
5. **理不尽への耐性、逆境**：「まるで軍隊だ!」「心身共に地獄の日々」「生きるか死ぬかの三ヶ月」。
6. **素直な自己変革**：「怠け者だった」自分を認め、茶髪をやめると道が開けます。失敗を笑いに変える語り口（「分かっていたことだが（笑）」）も特徴です。
7. **弱みの自覚と工夫**：体力ではスポーツ経験者にかなわないと認め、「待てよ」と考えて「分かったぞ!」に至ります。力勝負ではない突破口を探す姿勢です（中身は次回以降）。
8. **夢と悪夢、夢と現実**：タイトルの「夢を信じた」に対して、作中では「悪夢」「夢なら覚める」「これは現実だよ」という対比が置かれています（ep4_02）。
9. **感謝と春**：「大役をいただけて感謝だな」、就活の成功を「春が訪れた」と表現します（ウグイスや桜の描写もあります）。

## 5. 映像で使えそうなページ

1. **ep1_01（カラー）**：研修所へ向かうバス、富士山と一本道、カラフルなロボットの新入社員たちが乗る車内。唯一のフルカラー導入で、オープニングやタイトル明けに最適です。次ページの「はずだった・・・」と組むと暗転の予告になります。
2. **ep1_03（カラー）**：先輩が豹変するアップと、「地獄の九十日間が始まった」のコマ（先輩が指さし、新人がバスから駆け降りる）。色つきで動きもあり、「暗黒」パートの入口に向きます。

4. **ep3_04 下段コマ**：演台に立つネクマックスの後ろ姿と、「一人でも多くの方を幸せにできるようー」の吹き出し（小さく「ネクマックス」と注記あり）。企業の理念に結びつけやすい一枚です。
