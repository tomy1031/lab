# 研究ノート：ANAKATA の 科学的な 根拠

この アプリの それぞれの 説明が、どの くらい 確かなのかを 整理します。印の 付け方は、キップ・ソーンが『インターステラーの 科学』で 使った 3段階（Truth / Educated guess / Speculation）に、数学の 定理を 区別する 1段階を 足した ものです。

| 印 | 意味 |
|---|---|
| **確かな数学** | 定理として 証明されている（次元の 数え方、切り口、影、回転） |
| **確かな科学** | 実験・観測で 確かめられた 物理（逆二乗則、軌道、相対性理論の 時空図） |
| **有力な仮説** | 多くの 物理学者が まじめに 研究しているが 未確認（余剰次元、ブレーンワールド） |
| **推測（SF）** | 物理法則に 反するとは 言い切れないが、根拠の ない 想像（バルクから 過去に 力を 加える） |

## インターステラーの「5次元」とは

- 映画の 科学監修を した ソーンの 説明では、私たちの 宇宙は 4次元時空（空間 3 ＋ 時間 1）の「ブレーン（膜）」で、それが 5次元時空（空間 4 ＋ 時間 1）の「バルク」に うかんでいる。【有力な仮説】（Thorne 2014）
- 光や 物質は ブレーンに 閉じこめられ、重力だけが バルクに 出られる、という 考えは ブレーンワールド模型の 中心。【有力な仮説】（Arkani-Hamed, Dimopoulos, Dvali 1998; Randall & Sundrum 1999）
- 映画の テサラクトでは、部屋の「時間」が 空間の 方向として 並び、主人公は 重力を 使って 過去の 部屋に 信号を 送る。ソーン自身が これを **推測** に 分類している。【推測】
- この アプリの 6章は、テサラクトの「時間を 空間の 方向に 並べる」という 発想を、オリジナルの 部屋で 再現した もの。映画の セット・人物・音楽は 使っていない。

## 1章・3章・4章：見えない 次元を 知る 方法

人は 4次元の 空間を 直接 見る ことは できないが、次の 3つの 方法は 数学的に 正確で、実験でも 学習効果が 報告されている。

1. **次元の 類推**（1章・2章）：点 → 線 → 面 → 立体 と 同じ 操作を もう 1回 行う。n 次元立方体の k 次元の 面の 数は 2^(n−k)·C(n, k)。【確かな数学】
2. **切り口**（2章・3章）：低い 次元の 存在が 高い 次元の 物体を 見ると、通りぬける 切り口の 移り変わりとして 見える（Abbott 1884）。超立方体を 頂点から 通すと、正四面体 → 切頂四面体 → 正八面体 → … と なる。【確かな数学】
3. **影（投影）**（4章）：光源を 4番目の 軸の 上に 置いた 遠近投影。立方体の 影が「正方形の 中の 正方形」に なるのと 同じく、超立方体の 影は「立方体の 中の 立方体」（Hinton 1904; Banchoff 1990）。【確かな数学】
- 4次元の 回転は「軸」の まわりでなく「面」の 中で 起こり、独立な 回転面は 6つ（XY, XZ, YZ, XW, YW, ZW）。二重回転（XY と ZW を 同時に）では 中心 以外の 全ての 点が 動く。【確かな数学】
- 4次元の 正多胞体は 6種類（5, 8, 16, 24, 120, 600 胞体）、3次元の 正多面体は 5種類、5次元 以上は どの 次元でも 3種類（Coxeter 1973）。【確かな数学】
- 人は 練習で 4次元の 空間的な 判断を ある程度 身につけられる：4次元の 迷路を 解く 課題で 成績が 上がった（Aflalo & Graziano 2008）、VR で 4次元の 図形を 操作した 人が 4次元の 中の 距離や 角度を 推定できた（Ambinder ほか 2009）。【確かな科学（心理学の 実験結果）】

### 色と 言葉の 約束
- W 座標は 色で 表す：**橙＝アナ（+W）**、**青＝カタ（−W）**。投影では アナ側が 光に 近いので 大きく 描かれる。
- 2章の 住人の 視界は、平面上で 光線を 進めて 求めた **1次元の 像**。近い 物ほど 明るい。

## 5章：重力と 空間の 次元

- 重力の 強さが 1/r² なのは、力（重力の 流れ）が 半径 r の 球面（面積 ∝ r²）に 広がるから。空間が n 次元なら 力は 1/r^(n−1)（ガウスの 法則の 一般化）。【確かな科学】
- 4次元以上の 空間では、ニュートンの 重力でも 一般相対性理論でも、安定な 惑星の 軌道が 存在しない（Ehrenfest 1917; Tangherlini 1963）。1/r³ では 有効ポテンシャルが 角運動量の 項と 同じ 1/r² の 形に なり、少し 遅いと 落ち、少し 速いと 逃げる。【確かな数学・物理】
- どんな 初期条件でも 閉じた 軌道に なる 中心力は 1/r² と r に 比例する 力だけ（Bertrand 1873）。2次元の 重力（1/r）では 軌道は 閉じない。【確かな数学】
- **余剰次元の 実験**：大きな 余剰次元が あれば 短い 距離で 重力が 1/r² より 強くなる はず。ねじれ秤の 実験は 52 µm まで 逆二乗則を 確かめ、余剰次元が あるなら それより 小さい ことを 示した（Lee ほか 2020; 先行 Kapner ほか 2007）。【確かな科学】
- 余剰次元が 小さく 丸まっている（ADD 1998）、または 強く ゆがんでいる（Randall & Sundrum 1999）なら、私たちの 重力は 1/r² の まま。ソーンは 映画の バルクを ランドール型の ゆがんだ バルクで 説明した。【有力な仮説】
- 体験の ため、アプリの 重力定数は 現実よりも 大きく、軌道は 数秒で 1周する。比べている のは 力の「距離への 依存の しかた」だけ。

## 6章：時間を 空間の ように 見る

- 特殊相対性理論以降、時間は 空間と ひとつに なった「時空」の 1つの 方向として 扱われ、物体の 歴史は 時空の 中の 曲線（**世界線**）として 表される（Minkowski 1908）。この 部屋を 時刻ごとに 並べて 世界線を 描くのは、時空図の 見方 そのもの（空間の 次元を 1つ 時間に 回すため、部屋は とびとびに 置いている）。【確かな科学】
- 「過去・現在・未来が すべて 同じように 存在する」と 考える **ブロック宇宙** は、相対性理論と よく 合う 時間の 解釈の 1つ（哲学的な 立場で、観測で 決まる ことではない）。【有力な仮説（解釈）】
- 時空の 外（バルク）から 特定の 時刻に 力を 加える ことは、知られている 物理では できない。この アプリでは「もし できたら、その 時刻より 後だけが 変わる（因果律）」を 見せている。映画では 過去への 働きかけが 歴史と 矛盾 しない ループとして 描かれ、ソーンは これを 推測に 分類している。【推測】
- 部屋の 物理：重力加速度 9.81 m/s²、振り子は L = 0.9 m（小さな 振れでは 周期 2π√(L/g) ≈ 1.90 s、24° の 振れでは 約 1.92 s）、ボールは 反発係数 0.74〜0.8 と 転がり摩擦。【確かな科学（古典力学）】
