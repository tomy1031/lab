# チャット画面の実装メモ

1. **三列で目的を分ける。** 1536×1024を基準に、上部ナビ・中央ウィンドウ・下部ドックを配置する。中央はメンバー一覧約22%、自分への質問約26%、会話約52%のCSS Gridにし、各列を独立スクロールにする。会話ヘッダーと入力欄は固定する。
2. **参照のガラス表現を再現する。** 背景に日・カンボジアの3Dオフィスを敷き、控えめにぼかす。パネルは白〜水色の半透明グラデーション、`backdrop-filter: blur(20px)`、白い1px境界、角丸24px、青みのある柔らかな影を使う。本文の背面は白の不透明度を高め、読みやすさを優先する。
3. **メンバー一覧の所属を正確に保つ。** 大阪本社にネクマックス・さくら・松井亮・アイ・ルミ、東京オフィスに東京メンバー（仮）、プノンペンオフィスにNX-086・ソカ・ダリス・ダラを置く。生成画像で東京に表示されているアイ・ルミは実装時に大阪へ戻し、東京メンバーを補完する。部署見出しに国旗、各行に氏名・役割を表示する。
4. **人物とAIの状態を一目で伝える。** 人間はちびキャラクター、AIは白いロボットのアバターに統一する。オンラインは緑、作業中は青、離席は灰色の状態点とラベルを併用する。選択中のネクマックスには青いグラデーションと明瞭なフォーカス枠を付ける。
5. **「あなたへの質問」を最優先の操作にする。** 淡いオレンジの背景、未回答件数、質問元、質問本文、回答欄、「回答する」を一枚のカードにまとめる。予算の候補チップは入力の補助とし、回答ボタンで確定する。送信中は二重送信を防ぎ、成功後は緑の回答済みに移動する。失敗時は入力を保持する。
6. **メッセージ種別と進捗を分ける。** 依頼・質問・回答・引き継ぎ・報告・採用を文字付きバッジで表示する。人の回答待ちはオレンジ、完了は緑、通常操作は青に統一する。色だけに依存せず、種別・状態・時刻を読めるようにする。種別フィルターには選択状態と件数を表示する。
7. **日本語の可読性を整える。** Noto Sans JPなどを使い、本文15〜16px、行高1.6、氏名16pxの太字、補助情報12〜13pxを目安にする。濃紺の本文と低彩度の補助文字を分け、長い役割名は省略表示とツールチップで補う。会話の吹き出しは最大幅85%とし、送受信の左右を揃える。
8. **入力と返信の流れを短くする。** 会話入力には選択中の相手名、記憶を踏まえて回答する説明、添付、青い送信ボタンを置く。Enterで送信・Shift+Enterで改行とし、日本語IMEの変換確定時は送信しない。空欄では送信不可にし、新着時は下端にいる場合のみ自動スクロールする。
9. **共通ナビと操作性を維持する。** NEXTMAKE AIの上部バーと六項目のドックを常時表示し、チャットだけを青で強調する。アイコンは光沢のある立体表現で統一し、操作領域は44px以上にする。幅が不足する画面では質問欄を件数付きタブで開閉し、会話と入力欄の幅を確保する。キーボード操作と明確なフォーカス表示にも対応する。
