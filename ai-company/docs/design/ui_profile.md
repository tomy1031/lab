# プロフィール画面の改善・実装メモ

1. **記憶を主役にする配置**：1536×1024を基準に、上部バーと下部ドックを常時表示。右側の大きなプロフィールパネルを「人物情報：約320px」「記憶：約620px」に分け、社員一覧と3Dオフィスを左側と外周に残す。狭い画面では人物情報を折りたたみ、記憶を先に読める構成にする。
2. **ガラスの質感**：外枠は角丸28px、内部カードは20px。背景に半透明の白、`backdrop-filter: blur(20px)`、白い1pxの境界線、淡い青の影を組み合わせる。本文カードの白色不透明度は85〜95%にし、オフィス背景より文字の読みやすさを優先する。
3. **かわいい社員カード**：白いロボットの大きな丸形アバター、名前、役割、国旗付きの所属・席番号、状態の順に並べる。「社長の隣の席で、社長の分身として働く」は独立した青い補足カードで常に表示。人間社員には同じ枠組みでちびキャラを使う。
4. **人の判断待ちを明示**：現在のタスクはオレンジ色のカードにし、「イベント予算の承認待ち」と「最終予算の決定は社長の判断が必要」を分けて表示。確認依頼ボタンを隣接させる。青は通常操作、オレンジは人への依頼・判断待ち、緑は完了に統一し、色に加えてラベルも付ける。
5. **記憶タイムラインの構造**：「たまっていくコンテキスト」の見出し、蓄積の価値を伝える短文、件数、種類フィルターを上部に置く。仕事／相談／フィードバック／ふりかえり／メモを縦線とドットでつなぎ、各カードに種類・時刻・要点・背景を表示。新しい記憶を上に置き、長文は展開できるようにする。
6. **追加操作を固定**：記憶欄の下部に種類選択・入力欄・「記憶に追加」を固定し、一覧だけをスクロールさせる。入力中の文章を保持し、追加後は新しいカードを先頭に挿入して完了通知を表示。チャット入力とは見出しと配置を分け、記憶への保存を明示する。
7. **文字と補助情報の階層**：日本語はNoto Sans JPなどを使用し、名前24px、主要見出し20px、本文14〜16px、補助情報12px以上を目安にする。本文は濃紺、行高1.6。人格説明→スキル・言語チップ→完了／やり取り／登録の統計の順にまとめ、チップは折り返す。
8. **会話と管理操作の整理**：「このメンバーに話しかける」入力と青い送信ボタンを人物情報側に置く。3Dで見る／チャット／編集は小さな補助ボタンにまとめ、退職は控えめな赤文字で離して配置する。退職の実行時には対象名付きの確認を表示する。
9. **共通ナビゲーションと操作感**：ドックは参照画像と同じ光沢のある立体アイコンを使い、人材を青いグラデーションで選択表示。国旗には所属名を併記。ボタンは44px以上の操作領域、ホバー時の軽い浮上、キーボードのフォーカスリングを用意し、プロフィールを閉じたら元の社員カードにフォーカスを戻す。
