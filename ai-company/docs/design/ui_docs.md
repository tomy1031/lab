# 資料画面の実装メモ

1. **全体レイアウト**：1536×1024を基準に、上部ナビ・中央ワークスペース・下部ドックを配置する。中央は左440px程度のライブラリと右のプレビューに分け、間隔24pxを確保する。幅が狭い場合は資料一覧からプレビューへ切り替える構成にする。
2. **背景とガラス表現**：日本とカンボジアの3Dオフィスを背景に敷き、ぼかしと淡い青のオーバーレイで情報量を抑える。パネルは白〜水色の半透明、角丸20〜28px、白い細線、柔らかい青系の影を組み合わせる。本文面は白の不透明度を高くし、背景が文字に干渉しないようにする。
3. **ライブラリの階層**：プロジェクト名と件数を見出しにして成果物をまとめる。行内はファイル名、担当者と国旗、関連タスクの順で配置する。ファイル名は16px・太字、補助情報は12〜13pxとし、長い名前は省略表示とツールチップで補う。
4. **ファイル行と選択状態**：Markdown・HTMLを識別できる立体的なサムネイルを用意する。選択行は淡い青の背景・青の枠・左端のラインで強調する。行全体を選択可能にし、キーボードでも移動・決定できるようにする。ホバーとフォーカスには明確な表示を設ける。
5. **人物と状態**：AI社員は白いロボット、人間はちびキャラの丸いアバターを使う。日本・カンボジアの小さな国旗を担当者名に添える。完了は緑、人間の確認・対応待ちはオレンジのラベルにし、色に加えて必ず状態の日本語を表示する。
6. **読みやすいプレビュー**：タイトルバーにファイル名と「開く」「コピー」を固定し、本文だけを独立スクロールさせる。MarkdownとHTMLは読みやすい表示に整形する。本文は16px前後・行間1.7、見出しは24〜28pxとし、要点ボックス・表・余白で読む順序をつくる。
7. **検索と絞り込み**：「資料名・担当者で検索」を一覧上部に配置し、文書・HTML・国のフィルターをピル型で示す。選択状態を青で明示し、検索後は該当件数を更新する。該当なしの場合は条件の解除ボタンを表示する。
8. **操作のフィードバック**：「開く」は青のグラデーション、「コピー」は控えめな副ボタンにする。コピー成功時は「コピーしました」を短時間表示する。本文下の「関連タスクを見る」で成果物の作成背景へ戻れるようにする。
9. **共通ナビと配色**：NEXTMAKE AIの上部バーと6項目の下部ドックを常に見せ、「資料」のアイコンを青い立体タイルで強調する。文字は濃紺、主要操作は青、完了は緑、人間待ちはオレンジに統一する。ドックが本文や操作ボタンを覆わない余白を確保する。
