# ログイン画面 実装メモ

1. **レイアウト**：基準サイズは1536×1024。上部に高さ約88pxの共通バー、中央に幅約648pxのログインカード、下部に6項目のドックを配置する。カードとドックの間に約50pxの余白を確保し、小さい画面ではページ全体を縦スクロール可能にする。
2. **背景と奥行き**：日本側の桜・大阪城・タワー、カンボジア側の王宮・ヤシ、両国の社員と白いAIロボットを背景レイヤーに置く。背景画像だけに軽いぼかしと明るい青白のオーバーレイを適用し、フォームの文字にはぼかしをかけない。
3. **ガラスコンポーネント**：カードは角丸28px、入力欄は20px、ドックのタイルは24pxを基本とする。半透明の青白背景、白い1px境界線、`backdrop-filter: blur(20px)`、淡い青の外側シャドウと上辺の内側ハイライトで質感を再現する。非対応環境では背景をより不透明にする。
4. **情報階層と書体**：ロゴ→「おかえりなさい」→「日本とカンボジアを結ぶ AI オフィス」→入力欄→ログインボタン→初期アカウントの案内の順に読む構成。日本語はNoto Sans JPなどを使用し、見出し32〜40px、入力・ラベル16〜18px、補足14pxを目安に、濃紺で十分なコントラストを保つ。国旗は説明を補助する小さなアクセントとする。
5. **入力フォーム**：「ログイン名」「パスワード」はプレースホルダーとは別に常時表示するlabelを設置する。入力高さ56px以上、左右余白20px、ユーザー・鍵アイコンを添える。青いフォーカスリングを設け、`autocomplete="username"` と `autocomplete="current-password"` を指定。目のボタンでパスワードの表示を切り替え、読み上げ名も状態に合わせる。
6. **主操作と状態色**：「ログイン」はカード内の全幅ボタンとし、シアンからロイヤルブルーへのグラデーション、白い太字、右向き矢印で主操作を強調する。送信中は「ログイン中…」と進捗表示に切り替え、二重送信を防ぐ。人の操作待ちはオレンジ、実際の接続準備完了は緑と文字の組み合わせで示し、接続状態は実データに連動させる。
7. **共通ナビゲーション**：NEXTMAKE AIの上部バーと「プロジェクト／タスク／チャット／資料／人材／レポート」のドックを残す。モックでは遷移先のプロジェクトを青い発光と丸印で強調。ログイン前に認証が必要な項目を押した場合は画面内でログインを案内し、成功後に選択した遷移先を開く。
8. **歓迎演出と補足**：手を振るNexMaxはカード左下の独立レイヤーに配置し、入力領域を遮らない。「ようこそ！」と控えめな動きで歓迎し、`prefers-reduced-motion`ではアニメーションを停止する。初期アカウントの案内と `data/credentials.txt` はボタン直下に読みやすく配置する。狭い画面ではキャラクターを縮小してフォームを優先し、認証エラーは該当入力付近に文章で表示する。
