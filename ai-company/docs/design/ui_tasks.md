# タスク画面の改善・実装メモ

1. **画面構成**：1536×1024を基準に、上部ナビ、中央のかんばん、下部ドックを配置する。中央パネルは左右48px程度の余白を取り、背景の日本・カンボジアの3Dオフィスを周囲に見せる。
2. **ガラス表現**：中央パネルは白と水色の半透明背景、`backdrop-filter: blur(20px)`、白い1px境界線、青みのある柔らかな影で構成する。外枠は角丸26px、カードは20px。背景だけをぼかし、文字は鮮明に保つ。
3. **対応待ちを主役にする**：「人間の対応待ち」は他列より少し広くし、淡いオレンジの面と境界線で強調する。「1分待ち」をカード上部のピルで大きく表示し、列見出しの件数とは分ける。
4. **カードの情報順**：種別・状態、タスク名、プロジェクト名、説明、担当者、補足・操作の順で統一する。タスク名は17〜19pxの太字、本文は14px前後、補足も12px以上を確保する。長いプロジェクト名は2行までとし、クリックで詳細へ移動できるようにする。
5. **状態の色**：基本文字は濃紺、AI作業中と主操作は青、人間の対応待ちはオレンジ、完了は緑を使う。色だけに依存せず「AI」「人間」「生成中」「完了」のラベルとアイコンを併記する。
6. **フィルターと件数**：担当種別と拠点を別々のセグメントにし、各グループ内で選択状態を明示する。初期値は「すべて」「全拠点」。件数は各列見出しの右側にピル表示し、フィルター後の件数に更新する。
7. **AIの進捗**：「AI 作業中」にはライブ出力の短い抜粋、生成中ラベル、進捗バーをまとめて表示する。更新時にカードの高さを変えず、出力領域を固定する。点滅や発光は控えめにし、動きを減らす設定に対応する。
8. **人間の完了操作**：対応が必要な理由と担当理由を淡いオレンジの補足領域にまとめる。「対応して完了にする」はカード幅の青いグラデーションボタンとし、押下後は処理中表示を経て完了列へ移動、件数と後続タスクを更新する。失敗時はカード内に再試行を表示する。
9. **担当者と成果物**：人間はちびキャラ、AIは白いロボットのアバターで識別し、名前の横に日本・カンボジアの小さな国旗を置く。完了カードはコンパクトにし、「成果を見る」とファイルチップから成果を開く。列内は独立スクロールにする。
10. **ナビゲーション**：下部の6項目は参照と同じ光沢のある立体アイコンを使用し、「タスク」のみ濃い青と白いアイコンで選択表示する。操作領域は44px以上、キーボードフォーカスも明示し、狭い画面では列幅を維持して横スクロールにする。
