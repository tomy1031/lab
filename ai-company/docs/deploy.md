# 動かし方とセキュリティ（無料・いまのサブスクの範囲で）

## まず結論

| やり方 | お金 | Claude の使い方 | 複数人 | 向き |
|---|---|---|---|---|
| **A. claude.ai のアーティファクト版**（試験・デモ用・公開済み） | 0 円 | 承認する人の claude.ai アカウント（そのサブスクの利用枠） | ○（共有したメンバー。入力は全員、実行は承認する人） | 「Claude の中に埋め込む」「サブスク内」「サーバーを持たない」 |
| **B. 自分の PC か無料のサーバー ＋ Cloudflare** | サーバー 0 円・**Claude は API キー**（Max・Ultra・Team は毎月の API クレジットの範囲、超えたら従量課金） | 会社の API キー | ○ | いまの作り（Claude Code で本当に作業する）をそのまま使う |
| **C. 自分の PC で自分だけ** | 0 円 | 自分のサブスク（`claude` にログイン） | ×（自分だけ） | 試す・個人で使う |

### サブスクの規約で気をつけること（2026 年 11 月に公式ページで確認）

- **1 人のサブスクのログインで、同僚の分まで AI を動かす使い方はできません。**
  - Claude Agent SDK のドキュメント：「事前の承認がない限り、第三者の開発者が claude.ai のログインや利用枠を自分の製品で提供することは認めていない。API キーで認証すること」
    （[Agent SDK quickstart](https://code.claude.com/docs/en/agent-sdk/quickstart.md)・[overview](https://code.claude.com/docs/en/agent-sdk/overview.md)）
  - 法務のページ：Free・Pro・Max の資格情報で、他の人の分のリクエストを流すことは認めていない。OAuth のログインは、その契約者本人の通常の利用のため
    （[Legal and compliance](https://code.claude.com/docs/en/legal-and-compliance.md)）
  - 利用規約：アカウントのログイン情報を他人と共有しない（[Consumer Terms](https://www.anthropic.com/legal/consumer-terms)）
- そのため、**B で複数人が使うなら、会社の API キー**（`ANTHROPIC_API_KEY`。または Bedrock・Vertex）にします。
  - 2026 年 10 月 7 日から、**Max・Ultra・Team プランに毎月の API クレジット**が付きます。Agent SDK でも、プランにつないだ Claude Console の組織の API キーで動かせば、このクレジットを使えます（[ヘルプの記事](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan)）。
    - 金額は記事に書かれていないので、Console で確認してください。
    - 超えた分は従量課金です。Console で使用額の上限を決めておいてください。
  - 法務のページでも、API キーを「自分の組織の許可された人」のために設定して使うことは認めています（使った分はキーの持ち主に請求されます）。
- **「入力は複数人・実行は 1 人（承認する人）」の形の場合**：規約に合うかどうかは、承認するのが誰かでは決まりません。どの経路で、誰の資格で Claude を呼ぶかで決まります。

  | 実行のしかた | 手動で承認 | 自動承認 |
  |---|---|---|
  | A：承認する人のページだけが AI を呼ぶ（本人の claude.ai アカウント。ほかの人は入力を書き込むだけ） | ○ | △（本人がページを開いている間に、本人が決めた狭いルールで流すまで） |
  | B：自前のサーバー（Agent SDK）を、承認する人の**サブスクのログイン**で動かす | × | × |
  | B：自前のサーバー（Agent SDK）を、**API キー**（上のクレジット、または従量課金）で動かす | ○ | ○ |

  - **A の自動承認が △ の理由**
    - アーティファクトの AI は、ページを開いている本人の利用枠を使います。
    - 同僚の入力が、本人が見ないまま本人の枠で次々に動くと、利用規約の「アカウントを他人に使わせない」に近づきます。
  - **サブスクで B が × の理由**
    - サブスクのログインは、Claude Code や Claude のアプリそのものを使うためのものです。
    - Agent SDK で作ったアプリから、ほかの人の依頼をサブスクの資格で流すことは認められていません。
    - 人が承認しても、この経路は変わりません。
  - 判断に迷うときは、法務のページにあるとおり Anthropic の営業窓口に確認してください。
- **Claude Code on the web（クラウドのセッション）はサーバーの置き場所にはできません。** しばらく使わないと止まって消えます（[ドキュメント](https://code.claude.com/docs/en/claude-code-on-the-web.md)）。

## A. claude.ai のアーティファクト版（いまの試験・デモ用）

claude.ai の「アーティファクト」（公開できる Web ページ）の中で、この会社を動かします。サーバーは持ちません。
画面と 3D はサーバー版と同じです。中身の違いは `client/src/artifact/` にあります。

### しくみ：入力は全員、実行は承認する人 1 人

```
メンバー（共有された人）              承認する人（アーティファクトのオーナー）のページ
  ゴール・話しかけ・完了の報告            会社を動かす係（server/company.ts と同じ司令塔）
   → 自分の依頼箱（inbox/<自分>）  ──→   依頼箱を読む → 承認待ちに並べる
                                         「始める」 → オーナーの Claude（sample）で分解・作業
  みんなの画面  ←── 共有データベース（db）に、ゴール・タスク・やり取り・記憶・成果物
```

| 項目 | 内容 |
|---|---|
| 入る | claude.ai のアカウントのまま。初回に「参加」画面で名前・拠点・役割を入れる（パスワードは無い） |
| 承認する人 | アーティファクトのオーナー。ほかの人のゴールと AI への話しかけは、オーナーが「始める」を押すまで動かない |
| Claude を使うのは | **オーナーのページだけ**（オーナーの claude.ai の利用枠）。メンバーのページは Claude を呼ばない |
| 自動承認 | 設定で選べる（既定は手動）。**オーナーのページが開いていて、画面に見えている間だけ**。1 日の上限つき（既定 5 件） |
| 進むとき | オーナーのページが開いている間。閉じている間の依頼は依頼箱にたまり、次に開いたときに処理する |
| 同時に 2 つ開いたら | 会社を動かすのは 1 つのタブだけ（データベースの札で決める） |
| いま開いている人 | `room` の在席で、名札・オンライン表示・「承認する人のページが開いているか」に出す |
| やることストック | 各自の非公開の場所（`data/users/<自分>/`）。整理は手元の決まりで行い、Claude は使わない |

### できないこと（サーバー版との違い）

- **マイク**：アーティファクトのページではマイクが使えません。やることストックは文字で入れます（ドックの「メモ」）。
- **AI社員の道具**：ファイルの読み書き・Web の検索はありません。AI社員は手元の知識と同僚への相談で進め、成果物（Markdown・HTML）はデータベースに残します。
- **確かめのダイアログ**：ブラウザの確認ダイアログは出ないので、ページの中の確認画面にしています。
- **表記**：実在の会社のロゴ・社名は載せず、「AI OFFICE」の表記にしています。会社の前提（プロンプト）にも実在の社名・人名は入れていません。

### 共有のしかた

1. 公開したページ（自分だけが見られる状態）を開き、「オフィスを開く」でオーナーとして参加する。
2. 右上の Share で、メンバーを **Contributor（使ってデータを書ける）** で招待する。Viewer だと読むだけで参加できません。
3. メンバーはリンクを開いて「参加」する。最初は Claude の利用の確認は出ません（メンバーのページは Claude を呼ばないため）。
4. オーナーが最初に「始める」を押したとき、Claude の利用の確認が出ます。許可すると動き始めます。

### データベースのルール（公開時に宣言）

| 場所 | 読める | 書ける |
|---|---|---|
| 全体（ゴール・タスク・やり取り・記憶・成果物・設定） | 全員 | オーナー（と Editor） |
| `members/<自分>` | 全員 | 本人（AI社員の文書はオーナー） |
| `inbox/<自分>`（依頼箱） | 本人とオーナー | 本人 |
| `data/users/<自分>/`（やることストック） | 本人だけ | 本人だけ |

### 作り直して公開する

```bash
npm run build:artifact      # dist-artifact/ に page.html と公開するファイルの一覧（publish.json）
npm run dev:artifact        # ローカルで確かめる（claude.ai の代わりの道具。?as=名前 で別の人、?simspeed=10 で速く）
```

公開は Claude Code から Artifact の publish で `page.html` と `publish.json` のファイルを送ります（宣言は `client/src/artifact/paths.ts` の `DB_RULES` と、user・sample・room）。

## B. 自分の PC か無料のサーバー ＋ Cloudflare（いまの作りのまま）

1. **置き場所**
   - 社内でいつも電源が入っている PC か Mac が手軽です。
   - 無料のクラウドなら Oracle Cloud の Always Free があります。ただし 2026 年に無料枠が半分（2 OCPU・12GB）になったという報道があり、[Oracle の公式ページ](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm) で確認してください。
2. **起動**

   ```bash
   cd ai-company
   npm ci && npm run build
   NODE_ENV=production HOST=127.0.0.1 PORT=8787 TRUST_PROXY=1 COOKIE_SECURE=1 \
   ANTHROPIC_API_KEY=（会社の API キー） AI_ENGINE=claude AGENT_WEB=0 \
   npm start
   ```

   - `HOST=127.0.0.1` で、その PC の中だけで待ち受けます。ルーターのポートは開けません。
   - サーバーは、専用の一般ユーザー（管理者でない）で動かします。
3. **入口：Cloudflare Tunnel ＋ Cloudflare Access**
   - Zero Trust の無料プランは 50 人程度まで（[Cloudflare のプラン](https://www.cloudflare.com/plans/sase-zero-trust.md)）。
   - `cloudflared` をその PC に入れて、トンネルを作ります。外向きの通信だけなので、受け付ける口を開けずに済みます。
   - Access のアプリを作り、会社のメールアドレスのワンタイムコードか Google ログインに通った人だけを通します。
     - **アプリのログイン**と合わせて**二重の鍵**になります。
     - 同時に、ログイン画面に総当たりされることも防げます。
   - 公開する URL を `ALLOWED_ORIGINS=https://ai.example.com` に入れます。
4. **はじめにすること**
   - `data/credentials.txt` の初期パスワードで入ります。
   - 全員が右上の「パスワードを変更」で変えます。
   - 変えたら `credentials.txt` を消します。

### B を API キーで動かすときの費用の目安（2026-11-05 に実測）

ゴール「プノンペンの大学で開く日本企業説明会の告知文と当日の進行表を作る」を、Claude Code の既定のモデル（Opus 5.5）で通しました。
AI のタスク 4 件・人間のタスク 3 件、約 5 分でした。

| 内訳 | 金額（API の料金に換算） |
|---|---|
| 分解（ネクマックス） | $0.09 |
| AI のタスク 4 件 | $1.51（1 件 $0.17〜$0.65。成果物が長いほど高い） |
| 相談・ふりかえり・完了報告 | $0.12 |
| **合計** | **$1.73** |

同じ量の文字数で、モデルごとに $100 で何件できるかの目安です（実際の文字数はモデルで変わります）。

| モデル（`AI_MODEL`） | 1 ゴール | $100 で |
|---|---|---|
| Opus 5.5（既定） | 約 $1.7 | 約 55 件（平日 1 日 2〜3 件） |
| Sonnet 5.5 | 約 $0.9 | 約 110 件 |
| Haiku 5.5 | 約 $0.05 | 約 2,000 件（質は試してから） |

- 費用の大半は、AI社員が書く文章（出力）と、Claude Code が毎回読み直す前提（キャッシュ）です。
- 1 タスクの上限は `TASK_BUDGET_USD`（既定 $1.5）で止まります。
- サーバーのログに、1 回ごとの金額が `[cost] task $0.17（累計 $0.26）` のように出ます。
- Console で月の使用額の上限を決めておくと、クレジットを超えて請求されることを防げます。
- アーティファクト版（A）は API のクレジットを使いません。承認する人の claude.ai の利用枠を使います。

## C. 自分の PC で自分だけ

## このアプリに入っている守り

| 種類 | 中身 |
|---|---|
| 待ち受け | 既定は `127.0.0.1`（その PC の中だけ）。外へは Tunnel などの入口を通す |
| ログイン | <ul><li>パスワードは scrypt でハッシュする。10 文字以上で、推測されやすいものは断る</li><li>ログイン名が無くても同じ時間をかける</li><li>失敗はログイン名ごとに 10 分で 8 回、接続元ごとに 10 分で 30 回まで</li></ul> |
| セッション | <ul><li>クッキーは HttpOnly・SameSite=Lax で、HTTPS のときは Secure</li><li>鍵はハッシュだけを保存する</li><li>使わないまま 14 日、または発行から 30 日で切れる</li><li>パスワードを変えると、ほかの端末は切れる</li></ul> |
| よそのサイトからの操作 | 書き込みと WebSocket は、Origin が自分でなければ 403（CSRF・WebSocket の乗っ取り対策） |
| ヘッダー | <ul><li>Content-Security-Policy：スクリプトは自分のサイトのものだけ。ほかのサイトの枠には入れない</li><li>X-Frame-Options・nosniff・Referrer-Policy・Permissions-Policy・HSTS（HTTPS 時）</li></ul> |
| 権限 | 人間の登録・退職・頭脳の切り替えは管理者だけ。人間のタスクを完了にできるのは担当者と管理者 |
| ファイル | <ul><li>成果物の閲覧は、そのゴールの作業フォルダの中だけ（`..` を断る）</li><li>`state.json` と `credentials.txt` は本人しか読めない（0600）</li></ul> |
| 画面への表示 | <ul><li>文章はすべてエスケープしてから表示する</li><li>AI が作った HTML は、スクリプトを止めた枠（sandbox）で表示する</li></ul> |
| AI社員の道具 | <ul><li>ファイルの読み書きと Web だけ。Bash は既定で無効</li><li>実行の直前に毎回検査する（`server/engine/guard.ts`）</li><li>作業フォルダの外へは出られない（`..`・絶対パス・シンボリックリンクも実体で判定）</li><li>Web は https だけ。社内ネットワーク・localhost・クラウドのメタデータには行かせない</li><li>1 タスクに予算の上限がある</li></ul> |
| マイク・やることストック | <ul><li>マイクはこのサイトだけに許す（`Permissions-Policy: microphone=(self)`）。カメラ・位置情報などは使わない</li><li>ストックは本人にだけ配信する</li><li>ほかの人のストックは操作できない</li><li>送れるのは 1 分に 40 件まで</li></ul> |
| エラー | 想定外のエラーの中身は返さない |
| 依存 | `npm audit` で既知の脆弱性 0 件（2026-11-05） |

### 残るリスクと運用のお願い

- **プロンプトインジェクション**
  - AI社員が読んだ Web ページに悪い指示が仕込まれていると、成果物の中身をゆがめられるおそれがあります。
  - 気になる仕事では `AGENT_WEB=0` にし、Web を使わせないでください。
  - 成果物は人間が確認してから外に出してください。人間のタスクの「最終承認」がそのためにあります。
- **音声入力**
  - 話した声は、ブラウザの音声認識サービスで文字になります。Chrome・Edge なら Google や Microsoft のサーバーです。
  - 社外秘の話をするときは、文字で入力してください。
  - このアプリのサーバーが声そのものを受け取ることはありません。
- **更新**：月に 1 回は `npm audit` と `npm update` を実行し、OS の更新も入れてください。
- **バックアップ**：`data/state.json` を毎日、暗号化した場所にコピーしてください。
- **退職者**：ログインを止めるには、管理者が登録を外してください。Cloudflare Access の許可リストからも外してください。
