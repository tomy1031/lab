# KHMER GT — カンボジア リアルVRグランプリ

カンボジアの名所を舞台に、グランツーリスモのようなリアルな対戦カーレースを楽しめる **WebXR VR & ハンドジェスチャー完全対応** の 3D レーシングゲームです（three.js / WebXR / MediaPipe・ビルド不要）。

## 収録コース（全5コース）
1. **プノンペン・リバーサイド** — 王宮・独立記念塔・メコン川を望むトワイライト市街地サーキット
2. **アンコールワット・サンライズ** — 朝焼けの五塔中央祠堂・環濠・石門を巡る荘厳なグランプリコース
3. **裏アンコールワット 2099（サイバーパンク）** — 雨の鏡面アスファルト・レーザーと回転ホログラムを纏うサイバー中央塔・クメール語ネオン看板を駆け抜ける近未来コース
4. **ボコー山・クラウド峠** — 霧と雲海・旧ボコーパレス・連続ヘアピンのヒルクライム峠
5. **カンポット・リバー＆塩田** — 塩田・フランス植民地風街並み・巨大ドリアン像・胡椒農園の南国高速コース

## 操作方法（コントローラー不要で全操作対応）
- **VR ハンドトラッキング（Meta Quest 2 / 3 / 3S 等）**：両手で空中のハンドルを握ってステアリング、グーでアクセル、パー✋でブレーキ、✌️/👍でERSブースト。メニュー画面は人差し指でポイント＆ピンチで決定。
- **Webカメラ・ハンドジェスチャー（PC / タブレット）**：画面右上の「ハンドジェスチャー操作」をONにすると、メニュー画面も指差し＆ピンチ（または0.9秒ホールド）で全操作可能。
- **キーボード / ゲームパッド / タッチ**：`WASD` / 矢印キー、`Shift` でERSブースト、`Space` でドリフト、`C` で視点切替、`Esc` でポーズ。
