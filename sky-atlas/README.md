# SKY ATLAS — 世界の空を飛ぶ VR

本物の地形と衛星写真で、世界中の空を飛ぶ VR です。対応するのは Meta Quest 2/3 のブラウザ（WebXR）と、PC やスマホの画面です。
行きたいエリアを**ネットのある所でダウンロード**しておけば、**ネットのない所でも飛べます**。

**あそぶ：https://tomy1031.github.io/lab/sky-atlas/**

## なぜ Google Earth のデータではないのか

Google Earth と同じ立体の街は、Google Maps Platform の「Photorealistic 3D Tiles」として使えます。ただし規約で、前もって取得・保存・キャッシュすることが禁止されています（[Map Tiles API Policies](https://developers.google.com/maps/documentation/tile/policies)）。個人用でも、PWA のキャッシュでも同じです。
そこで SKY ATLAS は、**保存してよいオープンデータ**だけで世界を組み立てています。

| データ | 中身 | 使う範囲 |
|---|---|---|
| 衛星写真 | [Sentinel-2 cloudless](https://s2maps.eu)（EOX）。10 m、雲のない年ごとのモザイク | 世界中（ズーム 14 まで） |
| 航空写真 | 国土地理院（全国最新写真）／USGS（NAIP）／swisstopo（SWISSIMAGE）／IGN（BD ORTHO） | 日本・アメリカ・スイス・フランスで、中心から数 km（ズーム 17 まで） |
| 地形 | [Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)（AWS Open Data：SRTM・3DEP・EU-DEM など） | 世界中 |
| 地形（日本） | 国土地理院 標高タイル（dem_png） | 日本 |
| 建物 | OpenStreetMap（Overpass API）。高さ・階数が入っていればその高さ | 街のエリア（中心から 1.5〜2.5 km） |
| 地名検索 | Nominatim（OpenStreetMap） | 検索のときだけ |

ライセンスと出典は、ゲームの「データとライセンス」にも出しています。
Sentinel-2 cloudless の 2018 年以降の版は **CC BY-NC-SA 4.0（非商用）** です。商用で使うときは、2016 年版（CC BY 4.0）を選ぶか、EOX のライセンスが必要です。

## 遊び方

1. ネットのある所でページを開き、「世界の名所」「場所をさがす」「地図」から場所を選んで **ダウンロード** します。半径 25 km で約 30〜70 MB です。
2. 「★ ダウンロード済み」になったエリアは、ネットがなくても **VR で飛ぶ／画面で飛ぶ** で遊べます。ページそのものも、一度開けばオフラインで開けます（PWA・ホーム画面に追加すると便利）。
3. ネットがあれば、ダウンロードしなくても「オンラインで飛ぶ」で、その場で読み込みながら飛べます。

### 飛び方（9 種類）

メニューの「飛び方」で選びます。VR の中では B / Y で開くメニューの「飛び方」タブでも切りかえられます。

| 飛び方 | VR | 画面 |
|---|---|---|
| スーパーマン | トリガーを引くと、その手の向きへ飛ぶ（両手で速い）。離すとゆっくり止まる | W/S 前後・A/D 横・Space/C 上下・Shift 速く |
| 空中浮遊 | スティックでゆっくり移動。加速もおだやかで、いちばん酔いにくい | W/S/A/D・Space/C（ゆっくり） |
| 鳥 | 両腕を広げて滑空し、振り下ろして羽ばたくと上昇。傾けて曲がり、たたむと急降下 | Space 羽ばたく・A/D 曲がる |
| ムササビ | ウイングスーツ。腕を広げて滑空（約 3:1）。下げると急降下で加速、上げると減速。トリガーで上昇気流 | A/D 曲がる・W/S 急降下・引き起こし・Space 上昇気流 |
| ほうき | またがり、ほうきを手で向ける。トリガーで進み、離すと空中で止まる。向けた方へ景色が回る | W 進む・見た方へ曲がる |
| グライダー | 操縦席に座る。右スティック（またはグリップを握った右手）で傾けて旋回、前で速く、後ろで遅く。雲の下の上昇気流で旋回すると上がる（バリオの音つき）。トリガーでエンジン | A/D 傾ける・W/S 速さ・Space エンジン |
| 気球 | かごに乗る。トリガーでバーナー、A / X で弁。横へは風まかせで、風は高さで向きと強さが変わる | Space バーナー・C 弁 |
| ジェットパック | トリガーで手のひらから噴射。下に向けると上昇、傾けると進む。重力があるので両手でバランスをとる。A / X でホバー | Space 噴射・W/S/A/D 傾ける |
| 魔法のじゅうたん | じゅうたんの上で体を前に傾けると進み、左右に傾けて曲がる。右スティックで上下。トリガーでまん中を合わせ直す | W/S 進む・A/D 曲がる・Space/C 上下 |

- **VR 共通**：B / Y でメニュー。右スティックの左右で回転（30° ずつ／なめらか、グライダーでは操縦桿）。A / X でブレーキ（気球は弁、ジェットパックはホバー）。
- **画面**：マウスで見回す（クリックで固定、Esc で解除）。乗り物の飛び方では、見た方へ曲がります。Esc でメニューに戻ります。
- **スマホ**：ドラッグで見回し、右下のボタンで前進・上昇（羽ばたき・バーナー・噴射）・下降。

スーパーマン・浮遊・ほうき・じゅうたんは、地面からの高さで速さが変わります（低いとゆっくり、高いと速い）。グライダー・ムササビ・鳥・気球は、本物に近い物理で飛びます。

- グライダーの滑空比は約 35:1、ムササビは約 3:1、鳥は約 13:1 です。
- 気球は風に乗って進みます。

上昇気流はエリアごとに決まった場所にあり、上に積雲が浮かびます。山の斜面に風が当たる所でも上がれます。
VR 酔いを防ぐため、曲がるときや速さが変わるときは視野のまわりを暗くします（設定で切りかえ）。

## しくみ

- **`js/plan.js`**：エリアに必要なタイルの一覧です。細かいズームはエリアの中だけ、粗いズームは約 700 km 先まで覆うので、地平線まで本物の陸と海が見えます。ダウンロードと表示が同じ一覧を使うので、オフラインで表示が「ないタイル」を待つことはありません。
- **`js/tiles.js`**：タイルの保存（Cache Storage の `sky-atlas-tiles-v1`）と取得です。保存済みを先に使い、なければネットから取ります。サーバーにないタイル（海の上の航空写真など）は「ない」と記録して、次の候補（衛星写真や粗いズーム）を使います。
- **`js/terrain.js`**：地形を四分木の LOD で描きます。近くは細かく、遠くは粗くしたタイルを 24×24 の網目にし、標高で持ち上げて写真を貼ります。子タイルが 4 枚そろうまでは親を描き続けるので、穴は開きません。ほかに 2 つの工夫をしています。
  - 航空写真は撮影条件が衛星写真と違うため、同じ場所の衛星写真に平均色を合わせてつぎはぎを減らします。
  - 遠くの地面は、地球の丸みのぶん頂点シェーダーで下げます。
- **`js/buildings.js`**：OpenStreetMap の建物を Overpass API から一度だけ取り、小さなバイナリにして保存します。近くの建物だけを、400 m 四方ごとにまとめて立体にします。
- **`js/modes.js`**：9 種類の飛び方の物理と操作です。**`js/flight.js`** は共通の部分（地面との当たり、エリアの端、着地）を受け持ちます。
- **`js/air.js`**：空気の動きです。高さで向きを変える風、上昇気流（積雲の下）、斜面に当たる風の上昇を、エリアごとに同じ配置で作ります。
- **`js/props.js`**：自分のまわりに見えるものです。ほうき、グライダーの操縦席と計器、気球のかご・バーナー・球皮、じゅうたん、ムササビの膜、ジェットの炎、上昇気流の雲。
- **`js/audio.js`**：その場で作る音です。風、バーナー・噴射、グライダーのバリオ（上昇すると速く高く鳴る）。
- **`sw.js`**：ゲーム本体（ページ・コード・three.js）をオフライン用に保存します。地図データはゲーム自身の保存場所にあるので、ゲームを更新してもダウンロードは消えません。

## 開発

```sh
cd sky-atlas
npm i                   # テスト用（Playwright・IWER）
npm run serve           # http://127.0.0.1:8080/
npm test                # 4 つのテスト（すべて偽のネットで動く）
node tools/shots.mjs    # 本物のタイルでスクリーンショット（ネットが必要）
```

- `tools/smoke.mjs`：検索 → ダウンロード（タイル＋建物）→ ネットを切る → 画面で飛ぶ（地形・建物・地面・エリアの端）→ オフライン中は 1 件もリクエストが出ない → 削除
- `tools/modes.mjs`：9 種類の飛び方の物理を、作った入力で確かめます（滑空比、上昇気流での上昇、旋回の向き、風に流される気球、ジェットの重力、じゅうたんの傾きなど）
- `tools/xr.mjs`：Meta の WebXR エミュレーター（IWER、Quest 3）で動かします。トリガー飛行、B のメニュー（9 種類）、レーザーで鳥を選んで腕で旋回、気球のバーナー、グライダーの操縦桿、30° スナップ回転、VR の終了
- `tools/offline.mjs`：公開用ビルド → service worker → エリアをダウンロード → ネットとサーバーを止めて再読み込み → オフラインで飛ぶ
- `tools/mock.mjs`：テスト用の偽のネット（円すいの山・格子の写真・建物の格子・一部の航空写真は 404）
