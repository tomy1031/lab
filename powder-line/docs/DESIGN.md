# POWDER LINE 設計メモ — 体の 動きと 画面の 動きを 一致させる

## ねらい

1997 年の RPG に 入っていた スノーボードの ミニゲームの ような、**アーケードで 気持ちいい ダウンヒル**を VR で 遊べる ように する。遊びの 骨組み（斜面を 下り続ける・左右に 曲がって アイテムを 集める・障害物を よける・ジャンプ台・分かれ道・タイムと 得点で ランク）は その ジャンルの もの を 使い、**コース・キャラクター・絵・音楽・名前は すべて オリジナル**です（既存作品の キャラクター・コース・曲・見た目は 使っていません）。

そのうえで いちばん 大事に したのは「**自分の 体が した こと と、目に 見える こと が 食い違わない**」こと。VR の 酔いの 主な 原因は、目が 感じる 動きと 内耳（前庭）が 感じる 動きの 食い違いです。だから「どう 動いたら どう 動くか」を 物理の 式で つなぎ、ゲームの 都合で カメラを 動かさない ように しました。

## 体 → 画面の 対応表

| 体で する こと | 測り方（`js/body.js`） | 雪の 上で 起きる こと（`js/physics.js`） | 一致させる 工夫 |
|---|---|---|---|
| 体ごと 左右へ 傾く | 頭が 足（立ち位置）の 真上から 横に ずれた 量 dx → 体の 傾き φ = asin(dx / 0.92·身長) | 板が エッジに 乗り、横向きの（求心）加速度 **a = g·tan(3φ)** で 曲がる | 本物の ライダーは 遠心力と 重力の 合力が 体の 軸に 沿う ように 傾く：tan(傾き) = a/g。同じ 傾きは どの 速さでも 同じ 横 G。遅いと 小回り、速いと 大回り（半径 v²/a）。部屋で 傾けられる 10〜20° を 3 倍して 実際の 30〜60° に |
| しゃがむ | 頭が 立った 高さより 下がった 量 | 空気抵抗が 減り 速くなる（15° の 斜面で 54 → 65 km/h） | 目線が 下がるのは 頭の 位置 そのもの（ゲームは 何も しない） |
| 山側（後ろ）へ 体を 引く | 頭が 立ち位置より 後ろへ | 横すべりで ブレーキ（雪煙と 音） | 後ろへ 重心を 移すと 減速、という 実際の 感覚どおり |
| しゃがんで → すばやく 伸び上がる | 頭が 0.55 m/s 以上で 上がった 瞬間（直前に 4 cm 以上 下がっていた こと） | その フレームで 雪面の 法線方向に 跳ぶ（オーリー）。深く しゃがみ 速く 伸びるほど 高い。キッカーの 先（3 m 手前〜離れた 直後）なら ×1.25 | 伸び上がりの 速さ ＝ 跳ぶ 強さ。足を 床から 離さなくて よい（安全）。トリガーでも 跳べる |
| 空中で 体ごと 回る | 頭の 向き（ヨー）を 巻き戻さずに 足し合わせた 角度（720° は 720°） | 板が **1:1 で** 同じだけ 回る → 180・360・540… | 足もとの 板が 自分の 体と 同じ だけ 回る。着地で 板が まっすぐ（か 真うしろ＝スイッチ）なら 成功、90° ずれると 転倒 |
| 着地の 瞬間に ひざを 曲げる | 頭が 速く 下がる（着地の 前後 0.2〜0.25 秒） | ソフトランディング：衝撃で 失う 速さを 返し、ボーナス | 衝撃を ひざで 吸う 本物の 動きに ごほうび |
| 空中で 手を 足もとへ 下ろし グリップ | 手の 高さが 身長の 40% より 下、頭より 35 cm 以上 下 | グラブ（前の 手／後ろの 手 × つま先側／かかと側 で ミュート・メロン・インディ・ステイル） | 本物と 同じ 「板を つかむ」 動き |
| 手を のばして クリスタルに ふれる | コントローラーの 位置 | 1.5 倍の 得点＋その 手に 振動 | 手で 触った ところで 振動する |

## カメラを 勝手に 動かさない

- **ゲームは 頭を 動かさない**。動かすのは 足もとの 世界だけ。キャリブレーションで 測った 立ち位置（足）が いつも ライダーの 位置に 乗る ように、プレイ空間（`dolly`）ごと 運びます。頭は その 中で、あなたが 動いた とおりに 動く
- **地平線は 傾けない・揺らさない**。斜面でも カメラは 重力の 向きに まっすぐ（本物の ライダーも 斜面に 垂直では なく 重力に 沿って 立つ）。体を 傾けた ときの 景色の 傾きは、ヘッドセットが 測った あなたの 頭の 傾き そのもの
- **転んでも 視点を 転がさない**。白く フェードして、少し 上から 再スタート
- **曲がっても 景色を 回さない（標準）**：コースは いつも −z 方向へ 下り、左右に うねる だけ に 設計。視点の 向きを「斜面に 固定」に すると、景色は 前と 横へ 流れる（並進）だけで 回転しない。回転は 内耳が いちばん 敏感な 動きなので、これが いちばん 酔いにくい
- **「進行方向に 回る」も 選べる**：板と 一緒に 景色が 回る 本物どおりの 見え方。回る 速さは 自分の 傾きで 決まる（自分で 起こした 回転は 酔いにくい）うえ、0.2 秒の なめらかさと 視野しぼりを つけた
- **加速を なめらかに**：一定速度は 酔いにくく、速さの 急な 変化が 酔いやすい（Meta の 設計ガイド）。リングの 加速は 0.7 秒かけて、ブレーキも 摩擦で 連続的に
- **視野しぼり（ビネット）**：強く 曲がる・速い・景色が 回る ときに 視野の 端を 暗く（なし／弱／強）
- **足もとの 板と 輪**：下を 見ると 足の 下に 板（エッジの 角度で 傾く）と、立ち位置の 輪（頭の 位置の 点・しゃがみの 深さ・斜面の 下向きの 矢印）。動かない 足場が 見えると 酔いにくく、自分の 重心も 分かる
- **振動**：エッジが 雪に 食い込む 強さ（傾き × 速さ）で 連続して 震え、着地・接触・クリスタルで 強く 震える。目と 手の 感覚を そろえる
- **風の 音**：速さとともに 大きく 高く。エッジの 音は 傾きと ブレーキで 変わる

## 参考に した もの

- **Carve Snowboarding**（Meta Quest）：前の 手が 板の 前、後ろの 手が 板の 後ろを 操り、両手を 持ち上げると ジャンプ（速く 上げるほど 高い）、空中で グリップを にぎると グラブ、スピンも ある。レビューでは「最初は 直感的で ない」「頭の 後ろに 回した 手の 追跡が 外れて 勝手に 曲がる」という 声も あった。→ POWDER LINE では **曲がるのは 体（頭の 位置）**、手は バランスと グラブと クリスタルに 使う ことに した。ジャンプの「速く 動かすほど 高い」と グラブの グリップは 同じ 考え方
- **体を 傾けて 進む 移動の 研究**：傾きで 操作すると、スティックより 臨場感と 操作の 手応えが 増え、酔いは 同じか 少ない という 報告が ある（LeanOn ほか）。曲がる 方向へ 体を 傾ける（バイクの ように）と 楽だ という 指摘も → 体の 傾き ＝ 曲がる 方向 ＝ 求心力の 向き
- **Meta の 移動の 快適さの ガイド**：一定速度は 快適・加速度の 変化が 不快・ビネットで 視野の 端の 動きを 減らす
- 1990 年代の 家庭用 ゲームの スノーボード ミニゲーム：斜面を 下り続ける 視点、アイテム集め、分かれ道、障害物、ジャンプ、ランク という 遊びの 骨組み

## 数値（`TUNE` と `BODY`）

| 名前 | 値 | 意味 |
|---|---|---|
| `gain` | 3.0（設定で ×0.75 / ×1.35） | 体の 傾き → エッジの 傾き。体を 8° 傾けると 24°：時速 36 km で 半径 23 m、時速 65 km で 68 m の ターン |
| `maxEdge` | 62° | いちばん 深い エッジ（横 G 1.9） |
| `mu` / `muBrake` | 0.045 / +0.42 | 雪の 摩擦／横すべり |
| `dragStand` / `dragTuck` | 0.0095 / 0.0065 /m | 空気抵抗（立つ／しゃがむ）。15° の 斜面の 終端速度 54 / 65 km/h |
| `popBase` + `popExtra` | 1.8 + 2.0 m/s | オーリーの 速さ（強さ 0〜1）。キッカーの 先で ×1.25 |
| `BODY.pivot` | 身長 × 0.92 | 傾きの 支点から 頭まで |
| `BODY.dead` | 1.2 cm | 体の 自然な 揺れは 曲がらない |
| `BODY.popVy` | 0.55 m/s | 伸び上がりを ジャンプと みなす 速さ（ゆっくり 立つ 0.2〜0.4 m/s では 跳ばない） |
| `BODY.drift` | 25 秒 | 真ん中で じっと している 間だけ、立ち位置の 中心が ゆっくり あなたに 追いつく（部屋の 中で 少しずつ ずれても 大丈夫） |
| 物理の きざみ | 1/120 秒 | 描画の 速さに 関係なく 同じ 動き |

## コースの つくり（`js/course.js`）

雪面は 一つの 式です：**縦の 断面**（斜度の 積分。エルミート補間で 段差も 折れ目も ない）＋ **土手**（コースの 端から 40° で 立ち上がり 森へ）＋ **地形**（キッカー＝最後で 鋭く 切れる 曲面の 台、分かれ道の 島＝木の 生えた 丘、ローラー、コブ、ドロップ＝斜度が 一瞬 48° に なる 崖）。地面に 沿って 滑り、地面が 重力で 落ちる より 速く 下へ 逃げた とき（キッカーの 先・崖・こぶの 頂上）だけ 空中に 出ます。キッカーの 上の クリスタルは、その 台から 予想の 速さで 跳んだ ときの 放物線の 上に 置いて あります。

## 確かめ方

`tools/sim.mjs`（Node）で 物理と 体の 読み取りを、`tools/smoke.mjs` で PC の 画面を、`tools/xr.mjs` で Meta Quest 3 の エミュレーター（IWER）を 使った VR の 操作を、`tools/offline.mjs` で オフラインを 確かめます。本物の ヘッドセットでの 酔いにくさ・傾きの 感度は 人に よって 違うので、設定（視点の 向き・視野しぼり・曲がりやすさ・ジャンプ・スティック操作）で 調整できる ように しました。
