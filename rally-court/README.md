# RALLY COURT — リアル VR テニス

Meta Quest 2 / 3 で、本物のようにテニスをする WebXR ゲームです（three.js r186 + WebXR、ビルド不要）。
コントローラーがそのままラケットになり、振ったとおりに当たります。ボールは空気抵抗・回転（マグヌス効果）・
バウンドの摩擦まで計算して飛びます。部屋の中でダッシュはできないので、移動は次の 3 つから選べます。

| 移動方法 | しくみ |
|---|---|
| **足踏み・腕振り** | その場で足踏み（または走るように両腕を前後に振る）すると、**落下地点**――来るボールを打てる立ち位置――へ**まっすぐ**進みます。テンポが速いほど速く（自分の最高速度まで）、着いたら止まります。打ったあとは、足踏みすると定位置へ戻ります |
| **自動** | 相手が打ってから反応時間（初期値 0.2 秒）のあと、落下地点へ自動で動きます。速さは**自分の最高速度・加速・減速が上限**で、間に合わない球には間に合いません |
| **十字キー** | スティック（PC は矢印キー / WASD / ゲームパッドの十字キー）で自由に動きます。初期値は十字キーのような 8 方向・一定速度。アナログにも切り替えられます |

どの方法でも、部屋の中で実際に動いたぶんはそのまま加わります。数値はすべて、いちばん遊びやすい値を初期値にして、
PC のメニューと VR の中のメニュー（B / Y ボタン）で調整できます（「このタブを初期値に戻す」もあります）。

## 遊び方（Quest）

1. Quest のブラウザで **https://tomy1031.github.io/lab/rally-court/** を開く（WebXR は HTTPS が必要です）
2. メニューでモード（試合・ラリー練習・球出し・サーブ練習）と移動方法を選び、**VR をはじめる**
3. 周りを片づけ、ラケットを振っても何にも当たらないことを確かめる（**遊ぶ広さの目安：2 m × 2 m**）
4. 利き手のコントローラーがラケット。自分の腕と手が見え、指がグリップを斜めに握っています（テニスの握り）。反対の手の手首に、移動の速さ・足踏みのテンポ・打球の速さが出ます
5. サーブは、反対の手にボールを持っています。**トリガーを押して離す**と手が開いてトス。落ちてくるボールを打ちます
6. 反対の手をグリップ（利き手のすぐ上）に寄せると両手で握り（両手打ちバックハンド）、スロート（ラケットの首）に寄せると添え手になります

PC では **PC で遊ぶ**（後ろから見た視点）。**デモを見る**（`?demo`）は CPU どうしの試合です。

## 操作

| 操作 | VR（Quest） | PC |
|---|---|---|
| 打つ | ラケット（利き手）を実際に振る | クリック：ドライブ（トップスピン）、右クリック：スライス（J / K でも）。マウスの位置が狙う場所 |
| トス | 反対の手のトリガー（またはグリップ）を押して離す | Space |
| サーブ | 落ちてくるボールを打つ | トスのあとクリック |
| 移動 | 上の 3 つから選ぶ（足踏み・腕振り／自動／スティック） | 十字キーモード：矢印キー・WASD。足踏みモード：F を押している間 足踏み（150 歩/分、Shift で 190） |
| メニュー | B または Y（ゲームは止まる）。レーザーで指してトリガー | M / Esc、右上の「メニュー」 |
| 向きのリセット | スティックを押し込んで 1 秒（いま向いている方がネット） | — |

## モード

- **試合**：CPU と 1 セット（設定で 3 セット、4 ゲームのショートセット、ノーアドも）。6-6 でタイブレーク（7 点先取、2 点差）。
  フォルト・ダブルフォルト・レット、サーブのノーバウンド返球の反則、ツーバウンド、アウト、ネットを判定し、審判がコールします（音声は英語、表示は日本語）
- **ラリー練習**：点数なしで CPU と打ち合います。CPU はフォアとバックへ交互に、入れやすい球を返します。ラリーの回数と最長を表示
- **球出し**：マシンが同じ間隔で球を出し続けます（速さ・回転・コース・間隔を設定）。返球のイン/アウトを数えます
- **サーブ練習**：デュースサイドとアドサイドから交互にサーブ。入った数と最速を表示

## 初期値とその理由

| 項目 | 初期値 | 理由 |
|---|---|---|
| 移動方法 | 足踏み・腕振り | 体を使って追いかける感覚がいちばん本物に近い |
| 自分の最高速度 | 4.5 m/s | 一般の上級者がコートで出すダッシュは 4〜5 m/s（トップ選手で 5〜6 m/s） |
| 加速 | 7 m/s² | 0.64 秒で 4.5 m/s。一般の上級者の 1 歩目（トップ選手は 8〜9）。大きいほど VR 酔いしやすい |
| 減速（止まる強さ） | 10 m/s² | テニスは止まる・切り返す方が加速より強い |
| 最高速になる足踏みテンポ | 170 歩/分 | 100 歩/分（ゆっくり）で約 2 m/s、140 で約 3.4 m/s、170 で最高速 |
| 足踏みの感度 | 中（頭の上下 9 mm） | AETHERWALK（このリポジトリ）で Quest で調整した値 |
| 腕振りの効き | 1.0 | 腕振りだけでも足踏みと同じに進む。両方なら少し速い |
| 反応時間（自動） | 0.2 秒 | 人の単純反応時間 |
| 打点の高さ | 0.95 m | 腰の高さ。落下地点は、バウンド後に球がこの高さまで下りてくる所で計算 |
| ボールとの横の間合い | 0.85 m | 体の中心から打点まで（腕＋ラケット）。フォアかバックかは近い方（少しフォア寄り） |
| 打点の前後 | 0.4 m 前 | 打点は体の前 |
| 十字キー | 8 方向・最高速度 | 十字キーの操作感。アナログにも切り替え可 |
| ラケットの角度 | 前腕と 55° | テニスのグリップは手のひらに斜めに握るので、手首をまっすぐにしたとき前腕とラケットは約 55°（90° ならハンマーの握り）。ラケットはコントローラーの「握り」の座標（WebXR の grip space）に付けるので、画面の手とぴったり合う |
| スイングの強さ | 1.0 | 振った速さのまま（物理のとおり） |
| ショットアシスト | 0.2 | アウト・ネットになる打球だけを、速さと回転はそのままで 20% だけ入る方へ寄せる。0 で完全に物理 |
| トスアシスト／トスの高さ | オン／1.3 m | 手の上へまっすぐ。打点（約 2.7 m）より 0.3 m ほど上が頂点 |
| 相手の強さ | 3（中級） | グラウンドストローク約 100 km/h、ファーストサーブ約 150 km/h、ラリー平均 6 球ほど |
| 酔い止め | 0.45 | 自動で動いている間だけ視界のふちを暗くする |

## リアルにするための計算

- **コート**：ITF の寸法（23.77 m × 8.23 m、ネットの高さ 中央 0.914 m・シングルススティック 1.07 m、サービスライン 6.40 m）。線の外側の端がコートの境界で、ボールが線にかかればイン
- **ボールの飛び方**：重力＋空気抵抗（Cd 0.55）＋マグヌス揚力（C_L = 1/(2 + v/rω)）＋回転の減衰を 240 Hz で計算
- **バウンド**：中空の球として、反発（縦）と摩擦（横、すべり／転がり）を計算し、回転も変わる。ハード・クレー・芝はコートペースレーティング（CPR）がそれぞれ中速・遅い・速いになる値。2.54 m から落とすと 1.41 m まで弾む（ITF の検査値 1.35〜1.47 m）
- **ラケット**：ストリング面とボールの当たりを、前のフレームと今のフレームの間で**連続的に**調べます（ヘッドは 1 フレームで 30 cm 以上動くため）。当たった場所のラケットの速度（回転も含む）と、手で持ったラケットの見かけの反発係数（中央 0.42、先端 0.26、フレームはほとんど跳ねない）から、打球の速さと回転が決まります。芯を外すとラケットがねじれて方向がずれ、振動も強く長くなります
  - 例：18 m/s の球を 22 m/s で振り抜くと約 137 km/h、下から上にこすると約 1500〜2200 rpm のトップスピン、止めたラケットに当てると 4 割ほどの速さで返る
- **ネット**：白帯（テープ）は丸い縁として跳ね返り、ネットコードで落ちる・越えるが起こります。白帯より下に当たると手前に落ちます
- **腕と打ち方**：腕は肩・上腕（三角筋・力こぶ）・ひじ・前腕・手首（リストバンド）・手（指3関節と親指）の形で、肩から手首まで IK で曲げます。VR では、手がコントローラーの位置に、肩はヘッドセットから推定（目の下・後ろ、体の向きは顔の向きを両手の方へ少し引いたもの）、腕の長さは身長から。
  CPU（と PC のあなたの姿）のスイングは本物のフォームのキーフレーム：フォアは「ユニットターン（反対の腕を前へ伸ばし肩を回す）→ ラケットを立てて引く → ヘッドが落ちる → 手首が先行してヘッドが遅れて出る → 前で低から高へ当てる → 反対の肩へ巻きつくフィニッシュ（反対の手がスロートを受ける）」、バックハンドは両手打ち（最後まで両手）、スライスは片手で高い所から（反対の腕を後ろへ）、ボレーは短く、サーブは「構え → トスと同時にトロフィーポーズ → ラケットダウン → エッジから振り上げて回内して打つ → 体の前を横切るフォロー」。当たる瞬間はヘッドがちょうど打点を通り、速さも現実的（フォア 17 m/s、サーブ 40 m/s 相当）。相手が打つ瞬間にスプリットステップ、低い球は膝を曲げ、頭はボールを追います
- **CPU**：ボールの行き先を予測し、反応時間のあと人と同じ上限（最高速度・加速）で走り、届けば、狙い（コース・深さ・速さ・回転）を決めて逆算した軌道に、打ちにくさ（球の速さ・走らされた度合い）に応じたずれを足して打ちます。ミスもウィナーもこの結果として起こります
  - レベル 1〜5：最高速度 3.7〜5.6 m/s、反応 0.34〜0.16 秒、ストローク 76〜130 km/h、サーブ 112〜192 km/h

## テスト

```sh
cd rally-court
npm install            # playwright・iwer・three（テスト用）
npm test               # すべて
node tests/unit.mjs    # 物理・ショット計算・予測・ルール・足踏み検出・設定（92 項目）
node tests/sim.mjs     # CPU どうしの試合を最後まで（スコアが正しい・ラリーの長さと球速が現実的）
node tests/racket.mjs  # VR のラケットの当たり（72〜90 Hz の振りを取りこぼさない、芯・先端・フレーム、回転）、握りの角度、スイングのキーフレーム（打点・なめらかさ・腕が届く）
node tests/smoke.mjs   # ブラウザ：デモ、PC のラリーとサーブ、メニューと保存、十字キーと足踏み
node tests/xr.mjs      # Meta のエミュレーター（IWER、Quest 3）：VR 開始、ラケットと両腕、両手持ち、足踏み（頭の上下）で落下地点へ、メニュー、ボールを持つ手とトス
```

`node tests/serve.mjs 8080` で http://127.0.0.1:8080/ に開けます。URL の `?set=moveMode:auto,level:5` で設定を、
`?seed=N` で CPU の判断を固定できます。`dev/poses.html?set=fh|bh|slice|serve|misc` はストロークの姿勢の一覧、`dev/hands.html` は手の形の一覧です。

## 注意

- 実機（Quest）での確認は、Meta のエミュレーター（IWER）と PC のブラウザでのテストまでです。ラケットの握りの角度は
  コントローラーの持ち方で感じ方が変わるので、「ラケット」タブの角度（前腕との角度）と面の向きで合わせてください
- VR の肩とひじの位置はヘッドセットと手からの推定です（体そのものは計測していません）。腕の見た目のためだけで、当たり判定はコントローラーの位置で決まります
- 足踏み・腕振りモードは、頭の上下の揺れで足踏みを数えます。うなずき・しゃがみ・横への 1 歩は数えないようにしています。
  反応しないときは「足踏みの感度」を高に、勝手に進むときは低にしてください
- 審判の音声はブラウザの音声合成（英語）です。声がない端末では表示だけになります
