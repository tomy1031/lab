# STAR WEAVER

Meta Quest 2 / 3 向けのVRリズムエクササイズです（three.js + WebXR、ビルド不要）。
流れてくる星に手でタッチし、光の彗星を腕でなぞり、ポーズをキープして、光のカーテンを横ステップでよけます。
デスクワークで固まった **肩まわり（肩甲骨）を大きく動かす** ことを中心に組み立てています。**腰に負担をかけにくい** 動きに絞り、**前後の移動はゼロ** にしました。

## 遊び方（Quest）

1. Quest のブラウザで公開URLを開く（WebXR は HTTPS が必須です）
2. 「ENTER VR」を押し、正面を向いて立つ
3. 目の前のパネルの「START」に指先かコントローラーの先でタッチする（ボタンは押し込むタイプで、レーザーは使いません。指先の位置はリング型のカーソルで表示されます）
4. 正面のホログラムのコーチと同じように、両腕を横に広げて「T」の字で2秒キープすると腕の長さを測ります。的の位置はこの値で決まります
5. 初回は **チュートリアル**（約1分半）が始まります。星は手元で止まって待ち、彗星は手を重ねている間だけ進み、カーテンやバーは体を動かすまで止まって待ちます。コーチのまねをするだけで、6つの動き（TOUCH / RHYTHM / TRACE / POSE / SIDE STEP / DUCK）を順番に覚えられます。途中の SKIP でいつでも抜けられ、メニューの TUTORIAL からもう一度受けられます
6. モード（JOURNEY / QUICK / ENDLESS）を選んで ▶ PLAY

| 操作 | コントローラー | ハンドトラッキング |
|---|---|---|
| 星にタッチ／彗星をなぞる | 握った手の位置 | 手のひら |
| ボタンを押す | コントローラーの先端 | 人さし指の先 |
| 一時停止 | B / Y ボタン | 左腰の横に浮かぶ ⏸ を0.8秒長押し |
| 位置のリセット | Meta ボタン長押し、または一時停止 → RECENTER | 同左 |

Meta ボタンでメニューを開くと自動で一時停止します。再開すると3秒のカウントダウンのあとに続きから始まります。

### コーチ（お手本ホログラム）

正面2.4mの投影台に立つ、SF風スーツのトレーナーです。逆三角形の胴、筋肉の膨らみがある手足、光るバイザー付きのヘルメットで、胸のV字・中心線・ベルト・手足のラインが光ります（左半身は青、右半身はピンク）。鏡に映ったあなたのように動きます。たとえば、あなたの右手で取る星には、コーチがピンクの手を伸ばしてお手本を見せます。
ポーズ、彗星の軌道、横ステップ、スクワットの直前にお手本を見せ、ウォームアップ中は星へのリーチも実演します。設定の COACH で消せます。

## オフラインで遊ぶ（PWA）

Labサイト（https://tomy1031.github.io/lab/star-weaver/）を **一度オンラインで開くと、次からはネットにつながっていなくても遊べます**。

- 初回に、ゲーム本体・three.js・フォント・アイコンをすべて端末に保存します。トップページに **OFFLINE READY** と出たら準備完了です
- オフラインのときは、同じURLをブラウザで開くだけです。ブックマークしておくと便利です
- 対応するブラウザでは **INSTALL APP** ボタンからアプリとして追加でき、全画面で起動します（Quest のブラウザではアドレスバーのインストールボタンからも追加できます）
- 新しい版が公開されると、オンラインのときに上部へ「新しいバージョンがあります」と出ます。**UPDATE** で切り替わります。ページを開き直すだけでも最新になります
- 記録や設定はもともと端末内（localStorage）に保存しているので、オフラインでもそのまま使えます

仕組み：
- 公開用ビルド（`tools/build.mjs`）が、コードとフォントを内容のハッシュ名のフォルダ（`v/<build>/`）に置きます。これで古いファイルが残る心配がありません
- 同時に、保存するファイルの一覧を書き込んだ Service Worker（`sw.js`）と、版を知らせる `version.json` を作ります
- フォントは Google Fonts ではなく、使っている文字だけを切り出したファイルを同梱しています（`fonts/`、`tools/fonts.py` で生成、SIL OFL）

## スペース

- 横に約1.5m、前後に約0.8mあれば遊べます（横ステップ「小」なら横1.2m）。前後に歩く場面はありません
- ベッドの上では遊ばないでください。足場が不安定で、腰をひねりやすくなります
- 「座って」モードでは横ステップとスクワットが出ません。腰がつらい日はこちらで

## 中身

| 要素 | 動き | ねらい |
|---|---|---|
| 星（青＝左手、ピンク＝右手、金＝どちらでも） | 前・斜め上（Y）・真上・横・腰の高さへのリーチ | 肩の屈曲・外転、肩甲骨の上方回旋 |
| ふたつ同時の星 | 両腕を大きく開く→閉じる | 胸ひらき（大胸筋のストレッチ、肩甲骨を寄せる） |
| 彗星（点線の軌道） | 片腕／両腕の大きな円、虹（側方挙上）、∞ | 肩まわし、肩関節の可動域 |
| ポーズ WING / Y-RAISE | T字で胸をひらく／Y字に上げて2拍キープ | 肩甲骨の内転、僧帽筋下部 |
| うずまきの星 | 反対の手で体の前を横切る | 胸椎の回旋（腰ではなく胸から） |
| 光のカーテン | 矢印の方へ横に1歩 | 心拍数を上げる（前後の移動なし） |
| 光のバー | 軽くひざを曲げてくぐる | 下半身・ミニスクワット（LOW 10cm／MID 17cm） |
| クールダウン STARGAZE | のび、クロスボディストレッチ、胸ひらき、首をゆっくり回す（光を目で追う）、体側伸ばし、ゆっくり肩まわし | 整理運動 |

ステージは WARM-UP「FIRST LIGHT」 → STAGE 1「STARLIT LAKE」 → STAGE 2「METEOR STREAM」 → STAGE 3「STARFALL」 → FINAL「AURORA RUSH」 → COOL-DOWN「STARGAZE」の順です。

**腰への配慮**
- 的はすべて腰より上・体の前に出ます。床に手を伸ばす前かがみの動きはありません
- ひねりは「胸から」の小さめの回旋だけにしています。腰いたわりモードではさらに小さくし、体側伸ばしも省きます
- 3〜4分ごとに「お腹を軽く引きしめて」「呼吸を止めないで」などの声かけが出ます

**続けやすさ**
- ミスが続くと自動で「ゆったりモード」になり、星が遅く・当たり判定が大きくなります。慣れると元に戻ります
- コンボが伸びるほど音楽の楽器が増え、30コンボで FEVER（オーロラが強まり、スコア1.5倍）になります
- 連続プレイ日数、ベストスコア、からだレポート（肩まわし◯回・腕上げ◯回…）、推定消費カロリーを記録します
- 記録と設定はその端末のブラウザ（localStorage）にだけ保存されます

## モード

- **JOURNEY（約14分）**：ウォームアップ → 4ステージ（90→126 BPM）→ クールダウンのフルコース
- **QUICK（約6分）**：仕事の合間に。ウォームアップとクールダウン付き
- **ENDLESS**：ステージが続き、周回ごとに6 BPMずつ速くなります（最大140）。一時停止 → COOL DOWN で、ストレッチをしてから終了します

設定（メニュー右のパネル）：STANCE（STAND / SIT）、SIDE STEP（S 30cm / M 45cm / L 60cm）、SQUAT（OFF / LOW / MID）、BACK CARE、COACH、VOLUME

譜面は毎回ランダムに生成されます（ステージごとに出るパターンと出現しやすさは決まっています）。

## PCでのプレビュー

ページの PREVIEW ON PC でブラウザだけでも遊べます（マウス＝右手、左手は左右対称に動きます。A/D＝横ステップ、S＝スクワット、Space＝一時停止）。プレイ中は自分の少し後ろからの視点になります。
WATCH AUTOPLAY では自動プレイを眺められます。

URLパラメーター（テスト用）：`?autoplay` `?tutorial` `&mode=journey|quick|endless` `&speed=4`（時間を早送り） `&seed=42`（譜面を固定） `&nosound`

## 仕組み

- `index.html` … ランディングページ。three.js r186 は import map で jsDelivr から読み込み、フォントは Outfit と Zen Kaku Gothic New です
- `js/main.js` … レンダラー、WebXR セッション（`immersive-vr` / `local-floor` / `hand-tracking`、対応端末なら90Hz）
- `js/game.js` … 状態遷移（測定 → チュートリアル → メニュー → プレイ → リザルト）、採点、HUD、一時停止、難易度の自動調整、コーチへの指示
- `js/tutorial.js` … 体を動かすまで待ってくれる、ステップ式のチュートリアル
- `js/coach.js` … コーチ（旋盤形状で作った手足と胴、発光ラインのスーツ、2ボーンIKで動く鏡像のトレーナー、投影台）
- `js/chart.js` … 1小節単位のパターンからステージの譜面を生成
- `js/body.js` … 目の高さとT字の腕幅から肩の位置・腕の長さを推定し、的の位置を「肩からの角度×腕の長さ」で決める
- `js/entities.js` … 星（エネルギー球・照準リング）、彗星（光のチューブと尾）、ポーズ、カーテン、レーザーバー、光の粒
- `js/gfx.js` … 共通シェーダー（フレネル発光、ホログラム）、光のリボン、照準リング
- `js/handvis.js` … 手の表示（コントローラーは光る球と軌跡、ハンドトラッキングは25関節のホログラム）
- `js/screens.js` / `js/theme.js` / `js/text.js` / `js/ui.js` … VR内のパネル（ガラス調のカード、アイコン、指で押すボタンとカーソル）
- `js/audio.js` … WebAudio による音楽の自動生成（ドラム・ベース・パッド・アルペジオ・リード）と効果音。ゲームの時計は実際に耳に届いている音の時刻に合わせています
- `js/world.js` / `js/fx.js` … 星空、オーロラ、湖面のグリッド、パーティクル、ヒット時の閃光
- `js/desktop.js` … PCプレビューとオートプレイ

- `tools/build.mjs` … 公開用のオフライン対応ビルド（Labサイトの `site/build.mjs` から呼ばれます）
- `tools/fonts.py` / `tools/icons.py` … フォントの切り出し、アプリアイコンの生成
- `sw.js` / `manifest.webmanifest` / `js/pwa.js` … Service Worker のひな形、PWAマニフェスト、更新チェックとオフライン表示

## テスト

```bash
npm install
npm test
```

- `tests/smoke.cjs` … オートプレイでクイックモードを最後まで通し、エラーがないこととリザルトを確認
- `tests/tutorial.cjs` … オートプレイでチュートリアルの全ステップを通り、ALL SET! まで行くこと
- `tests/modes.cjs` … ENDLESS → COOL DOWN、SIT＋BACK CARE の譜面に壁・バー・体側伸ばしが出ないこと
- `tests/xr.cjs` … Meta の WebXR エミュレーター（IWER、Quest 3 プロファイル）で、VR開始 → ボタンを指で押す → T字測定 → チュートリアル最初の星 → SKIP → PLAY → コントローラーで星を打つ → Bボタンで一時停止 → RESUME → ハンドトラッキング → 終了 まで
- `tests/pwa.cjs` … 公開用ビルドを一度オンラインで開いて OFFLINE READY を確認 → ローカルサーバーを止め、インターネットも遮断して開き直し、オートプレイが動くこと → 新しい版を出すと更新の案内が出て、UPDATE で切り替わること
- `tests/shots.cjs` / `tests/screens.cjs` … 各オブジェクトと各パネルのスクリーンショット

## 自分で公開する

静的ファイルだけなので、HTTPS で配信できればどこでも動きます（GitHub Pages など）。オフライン対応にするには `node tools/build.mjs <出力先>` で作ったフォルダを配信します（そのままのフォルダでも遊べますが、オフライン保存はされません）。
PC で `npm run serve` したものを Quest から見る場合は、USB接続して `adb reverse tcp:8080 tcp:8080` を実行し、Quest のブラウザで `http://localhost:8080/` を開きます（localhost は HTTPS でなくても WebXR が使えます）。
