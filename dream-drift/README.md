# DREAM DRIFT — ドリーム・ドリフト グランプリ

8台で 走る カートレースです（three.js r186 + WebXR + MediaPipe Hand Landmarker、ビルド不要）。
**ゲームパッド・キーボード・スマホの タッチ**、**カメラの ハンドジェスチャー**、または **VR（Meta Quest 2 / 3）** で あそべます。
自分 1台と コンピュータ 7台（0〜7台で 変えられる）で、**ドリームカップ**（幻想的な 4 コース）と **カンボジアカップ**（アンコール・プノンペン・ボコー山・バッタンバンの 4 コース）を 走ります。

あそぶ：**https://tomy1031.github.io/lab/dream-drift/** （一度 開けば、次からは オフラインでも あそべます）

キャラクター・コース・アイテム・音楽は すべて この作品の ための オリジナルで、形・色・音は ほぼ コードで 生成しています。カンボジアカップの 砂岩と アプサラの レリーフの 画像、ゾウの 形は、同じ 作者の ゲーム「[NEXMAX CHRONICLE](https://github.com/tomy1031/nexmax_chronicle)」の クメール（1186年）の ステージから 使っています（`img/khmer/`）。

## あそびかた

1. ページを 開いて **スタート**（Enter / A ボタン / タップ / 手で ピンチ）
2. **あそびかた** を えらぶ：「コントローラ・キーボード」「ハンドジェスチャー（カメラ）」「VR（Meta Quest）」
3. **レースの 設定**：モード（グランプリ / フリーレース）、グランプリの カップ（ドリームカップ / カンボジアカップ）、スピード（やさしい / ふつう / むずかしい）、コンピュータの 数（0〜7）、周回数（1・2・3・5）
4. **キャラクター** を えらぶ（8人。スピード・加速・ハンドル・重さが 少しずつ ちがう）
5. フリーレースなら **コース** を えらぶ（2 つの カップの 8 コース）。グランプリは えらんだ カップの 4 コースを 順に 走り、順位の ポイント（15・12・10・8・6・4・2・1）の 合計で 総合順位が 決まります

## 操作

| 操作 | ゲームパッド | キーボード | タッチ（スマホ） |
|---|---|---|---|
| ハンドル | 左スティック / 十字キー | ← → / A D | 左下の スライダー（中心から 遠く さわるほど 大きく 曲がる。すべらせても OK） |
| アクセル | A（×）/ RT | ↑ / W | 自動 |
| ブレーキ・バック | B（○）/ LT | ↓ / S | ブレーキ |
| ドリフト（ジャンプ） | RB / LB | スペース / Shift | ドリフト |
| アイテム | X / Y | E / X | アイテム |
| ポーズ | スタート | Esc / P | 右上の II |
| メニュー | 十字キー・A で決定・B で もどる | 矢印・Enter・Backspace | タップ |

ゲームパッドは ブラウザの Gamepad API（標準配置）で 読みます。接続後に ボタンを 1回 押すと 認識されます。

### ハンドジェスチャー（カメラ）

| 操作 | ジェスチャー |
|---|---|
| ハンドル | 見えない ハンドルを 両手で にぎる ように 肩の 前に 出し、かたむける。右に 回すと 右へ。片手でも、手を かたむければ 曲がる |
| アクセル | 手が カメラに 映って いる あいだ 自動 |
| ブレーキ | 手を おろす（カメラから 外す） |
| ドリフト | 大きく 曲がり 続けると 自動で ドリフト。まっすぐに もどすと ミニターボ |
| アイテム | ピースサイン ✌（どちらの 手でも） |
| メニュー | 人さし指で ポインタを 動かし、親指と 人さし指を つまむと 決定（そのまま 1 秒 止めても 決定） |
| ロケットスタート | カウントダウンの「1」で 手を 上げる |

- 「ハンドジェスチャー」を えらぶと カメラの 許可を 求められます。準備画面で 手の 骨格と ハンドルの かたむきが 見えるので、確かめてから すすみます。
- 手の 認識は Google の MediaPipe（ブラウザの 中で 動く WebAssembly）です。**カメラの 映像は 端末の 中だけで 処理し、どこにも 送りません。** 初回だけ 認識モデル（約 8 MB）と プログラム（約 11 MB）を 読みこみます（ゲームに 同梱。オフライン用にも 保存されます）。
- 明るい 部屋で、カメラから 50 cm〜1 m ほど はなれると 安定します。ハンドルの 感度は「設定」で 変えられます。
- ジェスチャー中でも、ゲームパッドや キーボードを さわれば そちらが 優先されます。

### VR（Meta Quest 2 / 3）

Quest の ブラウザで ページを 開き、「VR（Meta Quest）」を えらんで 設定・キャラクター・コースを 決めると、そのまま VR で レースが 始まります。**すわって あそぶ** ように 作って あります。

| 操作 | Touch コントローラ | ハンドトラッキング（コントローラを 置く） |
|---|---|---|
| ハンドル | 両手の グリップ（中指の ボタン）を にぎって、ハンドルの ように 回す（片手なら 手首を かたむける、左スティックでも） | 両手を ハンドルの ように かたむける |
| アクセル | 右トリガー | 手が 見えて いる あいだ 自動 |
| ブレーキ・バック | 左トリガー | 手を おろす |
| ドリフト | A / X（曲がりながら 押して、押したまま） | 大きく 曲がり 続けると 自動 |
| アイテム | B / Y | ピース ✌ |
| ポーズ | 左スティック 押しこみ | Meta ボタン（ヘッドセットを はずしても 止まる） |
| 視点を 正面に もどす | 右スティック 押しこみ | レースの はじめに 自動 |
| メニュー | レーザーで ねらって トリガー | 指で ねらって つまむ |

- **ハンドル**：運転席では、ハンドルが **コントローラの 位置に あわせて** 出ます。両手の グリップを にぎって いる あいだは、2つの コントローラの まん中に、両手が ちょうど ふちに くる 大きさで 出て、手を 回した 角度の とおりに 回ります。はなすと、最後に にぎった 場所に そのまま 残ります。
- ゴールの あとは 前に 結果パネルが 出ます。レーザーで ねらって トリガーで「つぎの レースへ」（グランプリ）や「もう一度」を えらぶと、VR の まま 次の レースが 始まります。VR を とちゅうで やめると タイトルに もどります。
- スタート前に、操作の 早見表（ハンドル・アクセル＝右トリガー・ブレーキ＝左トリガー・ドリフト・アイテム）が 前に 出ます。
- **視点**：ふだんは 運転席（1人称）。ポーズメニューか「設定」で「後ろから」（3人称）に 切り替えられます。
- **酔いどめ**：坂や カーブでも 視界は 傾かず（向きだけ カートに ついて いく）、スピンしても 視界は 回りません。大きく 曲がって いる あいだは 視野の ふちが 暗く なります（「設定」の「VR 酔いどめ」で OFF に できます）。
- 視界の 左上に **アイテム**（拾うと ポンと 大きく なり、名前が 出ます）、右上に **順位・周回・タイム** の パネルが 出ます。ハンドルや 手で かくれない 高さで、道の 正面は あけて あります。3-2-1 や GOAL は 前方に 大きく 出ます。ぶつかった ときなどは コントローラが ふるえます。
- VR では 画質を 軽く します（光の にじみと 影なし）。

## レースの テクニック

- **ドリフト**：曲がりながら ドリフトボタンを 押すと ぴょんと はね、そのまま 押して いると 横すべりで 曲がります。向きは はねた ときの ハンドルで 決まり、押したまま あとから 曲げても ドリフトには なりません（ジャンプ台から 押したまま 着地した ときも ドリフトに 入れます）。ドリフトは 0.4 秒ほどかけて なめらかに 始まります。ハンドルを はなすと ふつうの カーブに ちょうど よい 曲がり方、曲がる 方へ 入れると きつく（ヘアピン用）、反対に 入れると ゆるやかな 大回りに なります。カメラは カートの 進む 向きを 追うので、カートは ななめに 見えたまま 画面は なめらかに 回ります。火花が 青 → オレンジ → ピンク と 変わるほど、はなした ときの **ミニターボ** が 長く なります。
- **ぶつかる**：カート どうしで ぶつかると はね返り、うしろから 追突すると 少し 減速します（追突された 方は 押し出されます）。火花が 散り、カートと 画面が ゆれ、コントローラや スマホ（対応 機種）が ふるえます。
- **ロケットスタート**：カウントダウンの 最後（「1」の あいだ）に アクセルを 押しはじめると、スタートで 加速します。
- **ダッシュパネル**（オレンジの 矢印）と **ジャンプ台**（にじ色の 帯）。ジャンプ中に ドリフトボタンを 押すと **トリック** で、着地の とき 加速します。
- 道の 外（ふち）は おそく なります。ターボ中は おそく なりません。
- かべに 当たっても、向きを 少し 道ぞいに もどして くれます。動けなく なったら 道の 上に もどります。

## ドリフト・ハンドルの 調整（テスト走行）

ドリフトの 曲がり方などの 数値を、走りながら 変えて 試せます。

- **「設定」→「ドリフト調整・テスト走行」**：CPU なし・周回 なし（99周）で すぐ 走り出し、左上に 調整パネルが 出ます。パネルの「コース」で 走る コースを 変えられ、「やり直す」で スタートに もどります。
- レース中なら **ポーズ →「ドリフト・ハンドルの 調整」** でも 開けます（URL に `?tune` を つけると レースの はじめから 開きます）。
- パネルの 上には 今の 速さ・曲がる 速さ（°/秒）・**曲がりの 半径（m）**・すべり角・ハンドルの 入力・ドリフトの 状態が 出ます。ふつうの カーブは 半径 40〜80 m、いちばん きつい ヘアピンが 25 m くらいです。
- 変えた 値は すぐ 走りに 反映され、**この 端末に 保存** されます（ふつうの レースでも 使われる）。初期値と ちがう 値は 黄色く なります。
- **「値を コピー」** で 全部の 値を コピーできます（例：`DREAM DRIFT 調整値 (変更 2 個: driftNeutral, driftIn)` の 次の 行に `{"driftNeutral":0.25,…}`）。コピーした 文字を 下の 枠に 貼り付けて「下の 枠から 読み込む」で もどせます。「初期値に もどす」も あります。

| まとまり | 数値 |
|---|---|
| ドリフト | ハンドルを はなした ときの 曲がり・内側に 入れた ときの 追加・外側に 入れた ときの 減り（× ふつうの いっぱいの 曲がり）、ドリフトに 入る／ぬける 時間、ハンドルの おくれ、曲がる 速さの おくれ、グリップ、開始に いる ハンドル、ジャンプ中の 曲がり、見た目の 角度 |
| ふつうの ハンドル | ハンドルの 強さ、高速での 弱まり、グリップ |
| 入力 | キー・十字キーで 切る 速さ／もどる 速さ、スティックと タッチの カーブ |
| カメラ | ドリフト中に 進む 向きを 追う 割合、カメラの 回る 速さ（ドリフト中・ふつう） |

## オフライン

公開版は、一度 開けば 次からは **ネットなしでも あそべます**（PWA。Quest の ブラウザでも 同じ。アプリとして 追加も できます）。

- three.js と MediaPipe は `vendor/` に 同梱して います。サービスワーカー（`sw.js`）が 最初に 開いた ときに ゲームの ファイルを 全部（約 3.6 MB）保存し、タイトルの 右下に「✓ オフラインでも あそべます」と 出ます
- ハンドジェスチャー（カメラ）の 部品（約 19 MB）は、一度 使うと 自動で 保存されます。先に 保存する ときは **設定 → 「ハンドジェスチャーも オフライン用に 保存」**
- VR の コントローラーの 模型（Quest 2 / 3 / Pro）は、VR が 使える ブラウザで 開くと 保存されます。文字（M PLUS Rounded 1c）は 一度 表示した 分が 保存され、ない ときは 端末の 丸い 文字に なります
- 新しい 版が 出ると、タイトルに「新しい バージョンに 更新」が 出ます
- 開発用の サーバー（`npm run serve`）では サービスワーカーは 動きません。公開用の コピーは `npm run build`（`node tools/bundle.mjs dist`）で 作り、
  `node tests/offline.cjs` で「保存 → ネットと サーバーを 切る → 開き直す → タイトル・レース・手の 認識の 起動」を 確かめます

## 動かす（開発）

ビルドは 不要です。静的ファイルを 配信すれば 動きます（カメラを 使うので `https://` か `http://localhost` で 開く）。

```sh
cd dream-drift
npm run serve          # http://127.0.0.1:8080/
npm install            # テスト用（Playwright と Meta の WebXR エミュレーター IWER）
npm test               # ジェスチャーの 判定（node）+ ブラウザでの 通しテスト + VR の 通しテスト（Quest 3 を エミュレート）
```

URL の オプション（テスト・確認用）：`?course=1`〜`4`（すぐ フリーレース）、`&autoplay`（自分の カートも CPU が 運転）、`&nosound`、`&quality=high|mid|low`、`&cpu=0〜7`、`&laps=1〜5`、`&cls=easy|normal|hard`、`&char=luna など`、`&skipintro`。
`window.DD.debug` に テスト用の 関数（`state()`・`simulate(秒)`・`view(周の 割合)` など）が あります。

## しくみ

| `js/race/ai.js` | CPU：レーシングライン（カーブの 内側）を 走り、他の カートや わなを よけ、ドリフトと アイテムを 使う |
| `js/race/items.js` | プリズムボックス、ルーレット、7 種類の アイテム |
| `js/race/race.js` | レースの 進行（紹介 → カウントダウン → レース → ゴール）、周回と 順位、カート同士の 衝突、ダッシュパネル、追い上げ補正 |
| `js/race/characters.js` | 8人の キャラクターと カートの モデル（形を 組み合わせて 生成）。顔は 8 表情の テクスチャ（キャンバスに 描いて 正面から 投影）、ばねで ゆれる 耳や しっぽ、表情と 頭の 動き（`animateDriver`）、顔アイコンと カートの 絵 |
| `js/ui/charpreview.js` | キャラクター選択の 回る 台（その場で 3D 表示） |
| `js/engine/input.js` | キーボード・ゲームパッド・タッチを まとめる |

| `js/vr/xr.js`・`vrinput.js` | VR の セッション（Quest の 72 Hz・フォビエーション）と 入力（グリップで にぎる ハンドル、トリガー、ボタン、ハンドトラッキング、振動） |
| `js/vr/cockpit.js`・`panel.js` | VR の 運転席：カートに すわる 視点（または 後ろから）、回る ハンドル、アイテムと 順位の パネル（左上・右上）、メッセージ、レーザーで 押す メニュー、酔いどめの 視野の ふち |

| `tools/bundle.mjs`・`tools/icons.mjs`・`vendor/` | 公開用の コピー（版の 番号と 保存する ファイルの 一覧を 入れる）、`img/icon.svg` から アイコンを 描く、同梱の three.js と MediaPipe |

画質は 3 段階（高：ブルーム＋影、中、低）。動きが 重いと 自動で 下がります。

## 確かめた こと・まだの こと

- VR（`tests/xr.cjs`、Meta の エミュレーター IWER で Quest 3 を 再現）：メニューから VR に 入る、右トリガーで 走る、両手の グリップで にぎった ハンドルで 左右に 曲がる、左スティックで ポーズ、レーザーと トリガーで メニューの ボタンを 押す、拾った アイテムが 左上の パネルに 絵つきで 出る（ハンドルより 上）、ゴール後の 結果パネル、ハンドトラッキングで 走る、「おわる」で VR を 出る。
- ブラウザ（ヘッドレス Chromium）で：メニューを キーボードで 進めて レースが 始まる、アクセルで 走る、ポーズと 再開、8 コース すべてで 8台が 完走（CPU が 引っかからず 道に もどされない）、バッタンバンで 列車が 通ると 遮断機が 閉じて CPU が 待ち、はねられない こと、結果画面。ジェスチャーの 判定は 合成した 手の 座標で 確かめています（`tests/gestures.mjs`）。
- オフライン（`tests/offline.cjs`）：公開用の コピーを 一度 開いて 保存 → 設定から ハンドジェスチャーを 保存 → ネットと サーバーを 切って 開き直すと、タイトル・レース・手の 認識（MediaPipe）の 起動が すべて 保存した ファイルで 動く。
- **本物の カメラと 手での 操作感**、実機の ゲームパッド、スマホの タッチ、**実機の Quest での 見え方・フレームレート・酔いにくさ** は、この 環境では 確かめられていません。
