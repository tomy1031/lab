# DREAM DRIFT — ドリーム・ドリフト グランプリ

8台で 走る カートレースです（three.js r186 + MediaPipe Hand Landmarker、ビルド不要）。
**ゲームパッド・キーボード・スマホの タッチ**、または **カメラの ハンドジェスチャー** で あそべます。
自分 1台と コンピュータ 7台（0〜7台で 変えられる）で、幻想的な 4 コースを 走ります。

あそぶ：**https://tomy1031.github.io/lab/dream-drift/**

キャラクター・コース・アイテム・音楽は すべて この作品の ための オリジナルで、形・色・音は コードで 生成しています（画像や 音声の 素材ファイルは 使っていません）。

## あそびかた

1. ページを 開いて **スタート**（Enter / A ボタン / タップ / 手で ピンチ）
2. **あそびかた** を えらぶ：「コントローラ・キーボード」か「ハンドジェスチャー（カメラ）」
3. **レースの 設定**：モード（グランプリ / フリーレース）、スピード（やさしい / ふつう / むずかしい）、コンピュータの 数（0〜7）、周回数（1・2・3・5）
4. **キャラクター** を えらぶ（8人。スピード・加速・ハンドル・重さが 少しずつ ちがう）
5. フリーレースなら **コース** を えらぶ。グランプリは 4 コースを 順に 走り、順位の ポイント（15・12・10・8・6・4・2・1）の 合計で 総合順位が 決まります

## 操作

| 操作 | ゲームパッド | キーボード | タッチ（スマホ） |
|---|---|---|---|
| ハンドル | 左スティック / 十字キー | ← → / A D | ◀ ▶ |
| アクセル | A（×）/ RT | ↑ / W | 自動 |
| ブレーキ・バック | B（○）/ LT | ↓ / S | ブレーキ |
| ドリフト（ジャンプ） | RB / LB | スペース / Shift | ドリフト |
| アイテム | X / Y | E / X | アイテム |
| ポーズ | スタート | Esc / P | 右上の II |
| メニュー | 十字キー・A で決定・B で もどる | 矢印・Enter・Backspace | タップ |

ゲームパッドは ブラウザの Gamepad API（標準配置）で 読みます。接続後に ボタンを 1回 押すと 認識されます。

### ハンドジェスチャー（カメラ）

| 操作 | ジェスチャー |
|---|---|
| ハンドル | 見えない ハンドルを 両手で にぎる ように 肩の 前に 出し、かたむける。右に 回すと 右へ。片手でも、手を かたむければ 曲がる |
| アクセル | 手が カメラに 映って いる あいだ 自動 |
| ブレーキ | 手を おろす（カメラから 外す） |
| ドリフト | 大きく 曲がり 続けると 自動で ドリフト。まっすぐに もどすと ミニターボ |
| アイテム | ピースサイン ✌（どちらの 手でも） |
| メニュー | 人さし指で ポインタを 動かし、親指と 人さし指を つまむと 決定（そのまま 1 秒 止めても 決定） |
| ロケットスタート | カウントダウンの「1」で 手を 上げる |

- 「ハンドジェスチャー」を えらぶと カメラの 許可を 求められます。準備画面で 手の 骨格と ハンドルの かたむきが 見えるので、確かめてから すすみます。
- 手の 認識は Google の MediaPipe（ブラウザの 中で 動く WebAssembly）です。**カメラの 映像は 端末の 中だけで 処理し、どこにも 送りません。** 初回だけ 認識モデル（約 8 MB）を 読みこみます。
- 明るい 部屋で、カメラから 50 cm〜1 m ほど はなれると 安定します。ハンドルの 感度は「設定」で 変えられます。
- ジェスチャー中でも、ゲームパッドや キーボードを さわれば そちらが 優先されます。

## レースの テクニック

- **ドリフト**：曲がりながら ドリフトボタンを 押したままに すると 横すべりで 曲がります。火花が 青 → オレンジ → ピンク と 変わるほど、はなした ときの **ミニターボ** が 長く なります。
- **ロケットスタート**：カウントダウンの 最後（「1」の あいだ）に アクセルを 押しはじめると、スタートで 加速します。
- **ダッシュパネル**（オレンジの 矢印）と **ジャンプ台**（にじ色の 帯）。ジャンプ中に ドリフトボタンを 押すと **トリック** で、着地の とき 加速します。
- 道の 外（ふち）は おそく なります。ターボ中は おそく なりません。
- かべに 当たっても、向きを 少し 道ぞいに もどして くれます。動けなく なったら 道の 上に もどります。

## アイテム

道に うかぶ **プリズムボックス** に ふれると アイテムが 出ます。うしろの 順位ほど 強い アイテムが 出やすく なります。

| アイテム | 効果 |
|---|---|
| ロケット | 1回 加速 |
| トリプルロケット | 3回 加速できる |
| ぷるぷるプリン | うしろに 置く わな。ふむと スピン |
| バブルショット | まっすぐ 飛んで、かべで はねる |
| ホーミングほたる | 1つ 前の 順位の カートを 追いかける |
| バリア | 攻撃を 1回 ふせぐ（9 秒） |
| スーパーコメット | 無敵で 加速。ぶつかった カートを はじく（6.5 秒） |

## 動かす（開発）

ビルドは 不要です。静的ファイルを 配信すれば 動きます（カメラを 使うので `https://` か `http://localhost` で 開く）。

```sh
cd dream-drift
npm run serve          # http://127.0.0.1:8080/
npm test               # ジェスチャーの 判定（node）+ ブラウザでの 通しテスト（Playwright）
```

URL の オプション（テスト・確認用）：`?course=1`〜`4`（すぐ フリーレース）、`&autoplay`（自分の カートも CPU が 運転）、`&nosound`、`&quality=high|mid|low`、`&cpu=0〜7`、`&laps=1〜5`、`&cls=easy|normal|hard`、`&char=luna など`、`&skipintro`。
`window.DD.debug` に テスト用の 関数（`state()`・`simulate(秒)`・`view(周の 割合)` など）が あります。

## しくみ

| ファイル | 内容 |
|---|---|

| `js/track/track.js` | コースの 道：閉じた スプラインを 約 2 m ごとに 区切り、「道の どこに いるか・地面の 高さ・中心からの ずれ」を 求める。道・ふち石・路肩・かべ・浮いた 道の 底面を 作る（カーブでは 道が かたむく） |
| `js/track/world.js`・`sky.js`・`props.js` | 空（グラデーション・星・星雲・オーロラを 1つの シェーダーで）、光と 影、地形、光る 粒、海の 光の ゆらぎ、スタートゲート |
| `js/courses/*.js` | 4 コース：道の 形（制御点）、色、アイテム・ダッシュパネル・ジャンプ台の 位置、景色、音楽 |
| `js/race/kart.js` | カートの 物理（加速・ハンドル・グリップ・ドリフトと ミニターボ・ジャンプ・かべ・路肩）と 見た目の 動き |
| `js/race/ai.js` | CPU：レーシングライン（カーブの 内側）を 走り、他の カートや わなを よけ、ドリフトと アイテムを 使う |
| `js/race/items.js` | プリズムボックス、ルーレット、7 種類の アイテム |
| `js/race/race.js` | レースの 進行（紹介 → カウントダウン → レース → ゴール）、周回と 順位、カート同士の 衝突、ダッシュパネル、追い上げ補正 |
| `js/race/characters.js` | 8人の キャラクターと カートの モデル（形を 組み合わせて 生成）、選択画面の 顔写真 |
| `js/engine/input.js` | キーボード・ゲームパッド・タッチを まとめる |
| `js/engine/hands.js`・`gesture-math.js` | カメラと MediaPipe、手の 形（グー・パー・ピース・指さし）と ハンドルの 角度、メニュー用の ポインタ |
| `js/engine/audio.js` | Web Audio：エンジン音・効果音・コースごとの 曲（ドラム・ベース・和音・アルペジオ・メロディを その場で 合成） |
| `js/ui/hud.js`・`nav.js` | レース中の 表示（アイテム・周回・順位・ミニマップ）、メニューの フォーカス移動と ハンドポインタ |

画質は 3 段階（高：ブルーム＋影、中、低）。動きが 重いと 自動で 下がります。

## 確かめた こと・まだの こと

- ブラウザ（ヘッドレス Chromium）で：メニューを キーボードで 進めて レースが 始まる、アクセルで 走る、ポーズと 再開、4 コース すべてで 8台が 完走（CPU が 引っかからず 道に もどされない）、結果画面。ジェスチャーの 判定は 合成した 手の 座標で 確かめています（`tests/gestures.mjs`）。
- **本物の カメラと 手での 操作感**、実機の ゲームパッド、スマホの タッチは、この 環境では 確かめられていません。
