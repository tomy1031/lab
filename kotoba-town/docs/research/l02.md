# Lesson 2 research notes — これは なんですか

## Grammar
| id | pattern | note |
|---|---|---|
| g1 | これ／それ／あれは Nです | near speaker / near listener / far from both |
| g2 | この／その／あの N | same distances, must be followed by a noun (also for people) |
| g3 | はい、そうです／いいえ、そうじゃ ありません | for noun questions; ちがいます is also common |
| g4 | S1か、S2か | choice question; answer by picking one, no はい／いいえ |
| g5 | N1の N2 — なんの N | content / topic (カメラの ざっし, にほんごの ほん) |
| g6 | N1の N2 — だれの N | ownership |
| g7 | Nのです | の replaces a thing already mentioned (not a person) |
| g8 | そうですか | falling tone, "I see" |
| g9 | これは なんですか | なん = what |
| g10 | ほんの きもちです／どうぞ／どうも ありがとう ございます／これから おせわに なります | gift and new-neighbour chunks |

Borrowed from slightly later lessons because the scene needs them: じてんしゃ (L5), おっと (L9).

## Real-life situations
Greeting new neighbours with a small gift, identifying unfamiliar objects, lost property ("whose is
this?"), exchanging business cards, being shown around a desk or room.

Moving-in etiquette (Japanese guide): visit within a week, about five minutes at the door, gift of
roughly ¥500–1,000 for neighbours (sweets, coffee, towels, everyday consumables), say who you are and
your unit, hand over the gift with a modest phrase, close with よろしく おねがいします.

## Common learner mistakes
- これ vs それ: the choice follows who the object is near, so it flips when the object changes hands
  (l02a makes the learner say これ, then それ for the same gift).
- この／その／あの used without a noun, or これ + noun.
- Answering an A-or-B question with はい／いいえ.
- Dropping の, reversing its order, or using わたしの when わたしのです (noun omitted) is meant;
  using の for a person.
- そうです used to answer adjective/verb questions later on — here it is limited to noun questions.
- そうですか said with rising intonation (sounds like doubt).
