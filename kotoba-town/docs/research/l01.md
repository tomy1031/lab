# Lesson 1 research notes — はじめまして

## Grammar
| id | pattern | note |
|---|---|---|
| g1 | N1は N2です | は = topic (pronounced "wa"); わたしは is usually dropped |
| g2 | N1は N2じゃ ありません | では ありません is the formal variant |
| g3 | N1は N2ですか | か question, same word order; answer はい、～です / いいえ、～じゃ ありません |
| g4 | Nも | replaces は ("too"); never は + も together |
| g5 | N1の N2 | affiliation: company / school + の + 社員 / 学生 |
| g6 | あの ひと／かたは だれ／どなたですか | かた・どなた are the polite pair |
| g7 | なんさい／おいくつですか、～さいです | おいくつ is polite; 20 = はたち |
| g8 | はじめまして／～から きました／どうぞ よろしく (おねがいします)、～さん | set chunks; さん never on one's own name |

Also used as chunks: しつれいですが, おなまえは？, こちらは ～さんです.

## Key vocabulary
わたし, あの ひと／あの かた, みなさん, ～さん, ～じん, せんせい (title) vs きょうし (own job),
がくせい, かいしゃいん vs ～の しゃいん (with a company name), ぎんこういん, いしゃ, エンジニア, だいがく,
だれ／どなた, ～さい, なんさい／おいくつ, はい／いいえ, country names.
Added for the town: デザイナー, ぶちょう (the cast's jobs).

## Real-life situations
First day at work, first class, being introduced to someone's boss, being mistaken for someone else,
polite small talk about job and age.

## Common learner mistakes
- Adding さん to one's own name (copied from how teachers address students).
- Overusing わたしは and あなた; Japanese uses the name + さん or drops the subject.
- なんさい to an adult/superior where おいくつ is expected; asking age without しつれいですが.
- は + も together; English word order with の ("社員の みどりデザイン").
- せんせい for one's own job (should be きょうし); かいしゃいん after a company name (should be 社員).
- Mixing politeness levels; shortening long vowels.
