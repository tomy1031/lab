# AETHERWALK — 風渡りの巡礼

Meta Quest 2 / 3 向けの WebXR オープンワールド・エクササイズ冒険ゲームです（three.js r186 + WebXR、ビルド不要）。
その場で **足踏み** すると島の中を歩けます。剣や弓は、腕を **実際に振って** 使います。歩いた歩数が「追い風」になり、止まった風をもう一度吹かせます。
部屋の中を動き回る場面はほとんどありません。遊ぶ広さは **約 1.5 m × 1.5 m** が目安です。

この README は、いまのコードで遊べるものだけを説明しています。設計書（`docs/DESIGN.md`）にあっても、実装されていない機能は含めていません。

## 遊び方（Quest）

1. Quest のブラウザで **https://tomy1031.github.io/lab/aetherwalk/** を開く（WebXR は HTTPS が必要です）
2. 読み込みが終わると押せるようになる **VR をはじめる ENTER VR** を押す
3. 周りを片づけ、腕を伸ばして一回りし、何にも当たらないことを確かめる
4. その場で足踏みを始める。ゆっくりでも歩けます。速く踏むほど速く進みます
5. **目覚めの石舞台** で目を覚まします。歩く・走る・枝を拾う・りんごを食べる・木人を叩く、を練習します（手首メニューの「記録」から飛ばせます）
6. 石舞台の燭台で松明に火を移し、旅人の野営地の焚き火に火を灯します。火が灯ると水筒が手に入り、台座の剣を手に取れます
7. 風見の鐘塔の頂で鐘を打つと、**風衣**（滑空）を得ます。残りの鐘塔を鳴らし、凪の心臓を鎮めるのが本筋です

**物語**：空に壊れた輪「天環」がかかるユラ島で、鐘の音が止んで風が止まりました。風の止まった場所には「凪」が溜まります。あなたは歩いて風を起こす「風渡り」です。四本の鐘塔を鳴らし、湖の小島で凪の心臓を鎮めると、島に風が戻ります。

## 足踏みで歩く

**歩数の数え方**：頭の位置から首もとの上下の動きを取り出して使います。うなずきや見回しはほとんど影響しません。足が着くたびに頭が一度沈むので、その沈みを1歩として数えます。次の動きは歩数に数えません。

- うなずき・見上げ
- しゃがむ（よけ）。しゃがみ終わって少しのあいだも数えない
- 横へ大きく動く・体を倒す。横の速さが速い間は数えない
- 武器を強く振って手が速く動いている間（小さな揺れを数えないようにする）

**足踏みの感度**（設定）は、どれだけ小さな揺れを1歩とみなすかです。反応しにくいときは「高」にします（高＝約6 mm、中＝約9 mm（既定）、低＝約13 mm の揺れ）。

**歩調から速さ**（spm = 1分あたりの歩数）。景色が流れて気持ちよくなるよう、実際より少し速めです。

| spm | 0–49 | 50 | 100 | 130 | 160 | 185 | 200 以上 |
|---|---|---|---|---|---|---|---|
| 速さ（m/s） | 0 | 1.2 | 2.0 | 3.2 | 4.6 | 6.0 | 6.5（上限） |

歩調は **歩く（50〜）・ジョグ（110〜）・走る（160〜）** に分かれます。1歩目で少し進み、1.25 秒以内に2歩目が来ると本格的に進みます。2歩目が来なければ、一度だけの揺れとして歩き出しを取り消します。最後の歩から 0.45〜0.9 秒ほどで止まります（ゆっくりの歩調では、1歩の間隔より 0.25 秒長く待ちます）。速さの変化はなめらかです。上り坂は遅くなり、急な坂は登れません。道の上は少し速くなります。

**腕ふりアシスト**（既定でオン）は、足踏みに合わせて腕を前後に振ると歩きやすくなる設定です。「腕ふりだけで歩く」（既定はオフ）をオンにすると、腕の振りだけでも歩けます。ただし、腕だけで歩いているときの速さは 0.7 倍です。

**速さの倍率**（0.7〜1.5）と、**進む向き**（頭・手）も設定で変えられます。

### 追い風（運動のごほうび）

追い風は、歩いたり走ったりすると溜まるゲージです。0 になっても歩けなくなることはありません。

| 増える場面 | 量 |
|---|---|
| 歩き・ジョグ・走りの1歩 | +0.4／+1.0／+1.5 |
| よけに成功（しゃがみ・横へ） | +8 |
| パリィに成功 | +10 |
| 4秒以上止まっている | 1秒あたり −2 |

| 段階 | 条件 | 効果 |
|---|---|---|
| 追い風 I | 50 以上 | 速さ ×1.08。武器の軌跡が明るくなる |
| 追い風 II | 100 以上 | 速さ ×1.15。与ダメージ ×1.25。10秒ごとに HP +1 |

上限は 100 で、風の種を集めると 160 まで伸びます。使い道は **風刃**（追い風 50 以上で、トリガーを握ったまま 5 m/s 以上で剣か槍を振ると刃が飛ぶ。−30）と、**滑空**（1秒あたり −4）です。

**滑空**：風衣を得たあと、空中で両腕を肩の高さに横へ広げ、両手の間隔を、両腕をいっぱいに広げた幅の 8 割以上にすると、ゆっくり降りながら前へ進みます。地面から 1 m 以上の高さが必要です。

## アイテムと武器

「入る場所」は体のホルスターです（右肩ごし・左肩ごし・右腰・左腰・胸のポーチ・腹のポーチ）。矢は弓を持つ手の逆の手で、肩ごしの矢筒から取ります。

| 名前 | 使い方（体の動き） | 入る場所 | 効果 |
|---|---|---|---|
| 旅人の剣 | 握って振る。突く | 右肩ごし・左肩ごし・右腰・左腰 | 斬り 6（強く振ると ×1.5）、突き 5。風刃を出せる |
| 風切りの槍 | 柄の向きに突く。投げる | 右肩ごし・左肩ごし | 突き 8、払い 4、投げ 10。届く距離 1.6 m。風刃を出せる |
| 枝の松明 | 棍棒として振る。火に近づけると燃える | 左腰・右腰・右肩ごし・左肩ごし | 打撃 3。燃えている間は敵を燃やす。明かり。火種になる |
| 木霊の盾 | 構えて受ける。攻撃に向けて押し出すとパリィ | 左肩ごし・右肩ごし | 正面 ±60° の攻撃を防ぐ。パリィで敵を2秒ひるませる |
| 風弓 | 片手で持つ。もう片手で肩ごしに矢を取り、引いて離す | 左肩ごし・右肩ごし | 引くほど強く飛ぶ |
| 矢 | 弓で放つ。先を火に触れさせると火矢 | 矢筒（肩ごし） | 4〜10 のダメージ（火矢は +3）。弱点は2倍。30 本まで持てる（風の種で増える） |
| 爆ぜ実 | 握ってトリガーで点火（火に触れても点く）。3秒後に爆発。投げる・転がす | 腹のポーチ | 半径 4 m。ひび岩を壊す。自分にも当たることがある |
| 石ころ | 拾って投げる | 腹のポーチ | 投げると 3。鈴を鳴らせる。澱み火を少し止める |
| 風扇 | あおぐ | 右腰・左腰 | 前方に突風。敵を押す、火を消す、飛び道具をはね返す |
| 息吹の水筒 | 口の近くで傾けて飲む。水に沈めて汲む。逆さにして注ぐ | 右腰・左腰 | 1口で HP +2。注ぐと火が消える。3口分 |
| 道しるべの鈴 | 振る | 左手首に下げてある | 追っている目的地へ光の帯が6秒伸びる |
| 陽りんご | 手を口へ運ぶ（2口） | 胸のポーチ | HP +4。火にかざすと3秒で焼き陽りんご（HP +8） |
| 灯りきのこ | 同上 | 胸のポーチ | HP +2、追い風 +30。焼くと焼き灯りきのこ（HP +6、追い風を満タン） |
| 霜いちご | 同上 | 胸のポーチ | HP +2。60秒のあいだ追い風が減らない |
| 風蜜 | 同上 | 胸のポーチ | HP を全回復。宝箱と祠で手に入る |

収集物は、光のかけら（通貨。触れるか 1 m 以内で集まる）、風の種（24個。集めると追い風の上限と持てる数が増える）、息吹の珠（祠のごほうび。最大 HP が 1 ハート増える）の3つです。

**組み合わせ**：火（松明・火矢・燃えている敵）は、爆ぜ実に火をつけ、食べものを焼き、いばらを燃やし、氷を溶かします。風（風扇・風刃）は、松明や火矢の火を消し、風車花を回し、澱み火の弾をはね返します。水は火を消し、水筒で汲めます。衝撃（爆ぜ実・強い振り）は、ひび岩を壊します。何でも投げられますが、自分の武器・道具は、手を離して8秒たつか 25 m 離れると、持ちもの（ホルスター）に戻ります。松明の火は約 180 秒もちます。

## 敵とたたかい

敵はすべてこの島のための創作です。体は灰色の殻で、芯だけが紫に光ります。攻撃の前には **赤い光（警告色）** が必ず出ます。予告のない攻撃はありません。

| 名前 | 出る場所 | 攻撃（予告 → よけ方） |
|---|---|---|
| いばら玉 | 島のあちこち（昼もいる） | 低く跳びかかる → 払う、盾、横へ1歩 |
| 凪の殻 | 鐘塔のまわり・峰（昼も）、夜は島の各地 | 横なぎ（頭の高さの赤い線）→ しゃがむか盾。縦の叩きつけ（足もとの赤い帯）→ 横へ1歩か盾 |
| 澱み火 | 森・峰（昼も）、夜は島の各地 | 赤い光の玉を遠くから撃つ → 体を傾けてよける、武器や盾ではじく、風扇で跳ね返す |
| 砂潜り | 峡谷 | 砂の下から突進（赤い帯）→ 横へ1歩。岩に当たるか盾でパリィされると3秒ひっくり返り、腹が弱点になる |
| 霜の番人（中ボス） | 霜の峰（2体） | 横の光線（頭の高さの赤い線）→ しゃがむ。地割れ（前方の赤い帯）→ 横へ1歩。氷のよろいは火で溶ける |
| 凪の心臓（ボス） | 湖の小島 | 3段階で戦う（「本筋とボス」を参照） |

**よけ方**：しゃがんで、頭を立ったときの高さの 8 割より下げると、頭の高さの攻撃をよけられます。横へ1歩で帯の攻撃をよけられます。盾は正面 ±60° からの攻撃を防ぎ、攻撃が当たる直前（0.25秒以内）に盾を攻撃の方へ押し出すとパリィになります。光の玉は武器で速く打てばはじけます。被弾後は1秒の無敵時間があります。

**倒れたとき**：HP が 0 になると「風に還る」になり、最後に火を灯した（または灯った灯のそばに寄った）風見の灯か、最後に鳴らした鐘塔のふもとで目を覚まします。持ちもの・かけら・進み具合は失いません。HP は全回復します。同じ場所で3回続けて倒れると、60秒のあいだ受けるダメージが半分になる「追い風の加護」がつきます。

## 島ユラ

島は6つの地域と海からできています。**鏡の湖**（中心。天の錨が浮かび、湖の小島がボスの場所）、**目覚めの丘**（南。出発点の草原）、**囁きの森**（西。巨木と霧、光るきのこ）、**茜の峡谷**（東。赤い台地とアーチ）、**霜の峰**（北。雪と氷、夜はオーロラ）、**潮騒の浜**（海ぞい。白い崖）です。

**鐘塔**（4本：丘・森・峡谷・峰）は、塔の中の丸い台に乗って足踏みすると昇れます。頂上で鐘を強く打つと目覚め、その地域の地図が色づき、地域の祠が地図に出ます。目覚めた塔は復活地点にもなります。

**祠**（5か所）は運動の挑戦です。輪の中に入ると始まり、何度でも挑めます。

| 名前 | 挑戦 | 使うもの |
|---|---|---|
| 疾走の祠 | 150 spm 以上で合計 40 秒走ると、6つの燭台が順に灯る（90 秒以内） | なし |
| 灯しの祠 | 祠の火を松明に移し、約 130 m 先の燭台まで 45 秒以内に運ぶ | 松明 |
| 身かわしの祠 | 流れてくる光の梁を、しゃがむか横へ1歩でよける | なし |
| 剣舞の祠 | 矢印つきの的を、矢印の向きに斬る | 剣か槍 |
| 射手の祠 | 海の岩の上の的を、弓で射る | 弓（祠が矢を貸す） |

**風の種**（24個）は、光の輪を走り抜ける「走り輪」、鈴を鳴らす「眠り鈴」、風扇であおぐか走り抜けると回る「風車花」の3種類で、各8個です。4個ごとに1段階強くなります（追い風の上限 +10、矢・爆ぜ実・石ころ・食べものの持てる数 +2。全6段階）。

**風見の灯**（焚き火）は島に5か所あります。復活地点で、料理ができ、「ひと休み」もできます。ひと休みでは時刻を朝・夕・夜に進められます。

**絶景**（7か所）：目覚めの眺め／風見の塔の頂／大樹ヨルハの木漏れ日／風穴のアーチの夕陽／氷鏡のオーロラ／白波の岬の朝焼け／祈りの桟橋の星鏡

**時間**：1日は現実の 24 分です（ゲームの1時間 = 60 秒）。朝7時から始まり、夜は凪の殻と澱み火が増えます。凪の心臓を鎮めたあとは、凪は夜にしか出ません。天気は地域ごとの空気（森の霧、峰の粉雪、峡谷の砂の筋、浜の波しぶき）だけです。

**本筋とボス**：焚き火 → 鐘塔 → 光の橋 → 凪の心臓、の順に進みます。凪の心臓は次の3段階です。
1. 守り石3つを壊す。心臓は頭の高さの光線（しゃがむ）と、澱み火を呼ぶ
2. 風が止まる。その場で速く駆け足（140 spm 以上）を合計 20 秒続けると殻がはがれる
3. 8秒間、芯を攻撃できる。終わると 2 に戻る

## 記録

| 項目 | 内容 |
|---|---|
| 歩数・距離 | 歩数の合計。距離はゲーム内の移動距離（km）。参考に歩数 × 0.7 m の換算も出す |
| アクティブ時間 | 足踏みや、手を速く動かしている時間 |
| 消費カロリー（目安） | 歩き・ジョグ・走り・戦いの強さ（MET）と体重から推定。体重は設定（既定 60 kg） |
| 最高の歩調・日ごとの履歴 | その日の一番速い歩調。直近60日分 |

**消費カロリーは目安です。** 手と頭の動きから推定した数値で、医療的なものではありません。

記録と設定は、その端末のブラウザ（localStorage）にだけ保存されます。キーは `aetherwalk.save.v1`（進み具合・記録）と `aetherwalk.settings.v1`（設定）です。ブラウザのサイトデータを消すと、どちらも消えます。

## スペースと安全

- 広さは **約 1.5 m × 1.5 m**。前後に歩く場面はありません
- 遊ぶ前に周りを片づけてください。Quest の境界（Guardian）を設定しておくと安心です
- ベッドやラグの上では遊ばないでください
- 痛み・しびれ・めまいが出たら、すぐに中止して休んでください
- 頭が中心から 0.45 m 以上離れると、足もとに中心のリングが出て、戻るよう促します
- 20分以上続けて動くと「ひと休みしませんか」と出ます（強制ではありません）。手首メニューで「今日はここまで」を選ぶと、60秒のゆっくり歩きのあと、今回の記録が出ます

**快適に遊ぶための設定**（ランディングページと手首メニューから変更）：向きを変える（スナップ 30°／45°、またはスムーズ）、ビネット（なし／弱／強。既定は弱）、ノックバック、崖の縁で止まる、しゃがみの深さ（ふつう／浅い）、座って遊ぶ、画質、振動。「座って遊ぶ」をオンにすると、しゃがみ攻撃は盾で受けられる攻撃に置き換わり、「腕ふりだけで歩く」も自動でオンになります。

## オフラインで遊ぶ（PWA）

Lab サイト（https://tomy1031.github.io/lab/aetherwalk/）を **一度オンラインで開くと、次からはネットにつながっていなくても遊べます**。

- 初回に、ゲーム本体・three.js・アイコンを端末に保存します。準備ができるとページに表示が出ます
- オフラインのときは、同じ URL を開くだけです。ブックマークしておくと便利です
- 対応するブラウザでは **アプリとして入れる INSTALL** で、アプリとして追加できます
- 新しい版が公開されると、オンラインのときに **新しい版に更新 UPDATE** が出ます。押すと切り替わります
- 公開用ビルド（`tools/build.mjs`）は、コードを内容のハッシュ名のフォルダ（`v/<build>/`）に置き、保存するファイルの一覧を書いた `sw.js` と、版を知らせる `version.json` を作ります

## PC でのプレビューと URL パラメーター

テスト用の URL パラメーターです。例：`?desktop&nosound&fresh&seed=1`

| パラメーター | 働き |
|---|---|
| `?desktop` | PC の操作（キーボード・マウス）で動かす |
| `?autoplay` | 自動プレイ。保存データを読み書きしない |
| `?seed=42` | 草木・岩・雲の散らばりを決める数（既定 7）。地形の大きな形は変わらない |
| `?t=17.5` | 時刻を指定（0〜24 時） |
| `?pos=x,z,yaw` | 立つ位置（m）と向き（度）。例：`?pos=0,540,0` |
| `?nosound` | 音を鳴らさない |
| `?fresh` | 保存データも設定も読まず、書きもしない |
| `?quality=low` | 画質を指定（auto／low／mid／high） |

**デバッグ API**：開発者ツールで `window.AW` を使えます。`AW.ready` は世界ができると true になり、`AW.errors` に読み込みのエラーが入ります。`AW.debug` には `state()`（位置・HP・追い風・歩数などを返す）、`teleport(x, z, yaw)`、`vista(id)` と `vistas()`、`setTime(h)`、`give(id, n)`、`equip(id, hand)`、`spawnEnemy(type, dx, dz)`、`damage(n)`、`heal(n)`、`god(true)`、`setStage(n)`、`simulateSteps(spm, seconds)` などがあります。

```

docs/                設計書（DESIGN.md）と絶景のスクリーンショット（docs/shots）
js/main.js           起動、URL パラメーター、描画ループ。PWA の更新確認は js/pwa.js
js/core/             入力、設定、イベント、ループ、WebXR、AW.debug
js/world/            島の地形、空、水、草木、地域、ランドマーク（landmarks/）
js/player/           足踏みの検出、移動、ホルスター、つかむ、滑空、PC 操作（desktop.js）
js/items/            アイテムの定義（defs.js）と、剣・弓・盾・爆ぜ実などの動き
js/game/             本筋、敵（enemies.data.js）、祠、鐘塔、風の種、記録、保存
```

制作の分担は次のとおりです。設計・風景・景観の監修 = Fable、本体の実装 = Opus、品質に影響しないコード（ツール・テストの下地）= Haiku。

## テスト

```bash
npm install
npm test
```

`npm test` は次の3つを順に実行します。

- `tests/smoke.cjs`：世界が読み込まれ、足踏みで移動でき、30秒の自動プレイがエラーなく動く
- `tests/shots.cjs`：各地点と絶景のスクリーンショットを `docs/shots/` に書き出す（実行のたびに上書きされます）
- `tests/xr.cjs`：Meta の WebXR エミュレーター（Quest 3 の設定）で VR を開始し、フレームが描かれ、頭の上下が歩きとして数えられ、コントローラーの振りでエラーが出ない

単独で実行するもの：`npm run test:pwa`（`tests/pwa.cjs`。オンラインで開いた後に、オフラインでも起動し、新しい版への更新ができること）。`tests/serve.cjs` は、テストが使う静的サーバーです。

## 自分で公開する

静的ファイルだけなので、HTTPS で配信できる場所ならどこでも動きます（GitHub Pages など）。

- オフライン対応の版は `node tools/build.mjs <出力先>` で作り、そのフォルダを配信します（`npm run build` は `dist/` に出力）。そのままのフォルダでも遊べますが、オフライン保存はされません
- PC で `npm run serve` を実行すると、`http://127.0.0.1:8080/` で見られます
- Quest から PC の画面を見るには、USB で接続して `adb reverse tcp:8080 tcp:8080` を実行し、Quest のブラウザで `http://localhost:8080/` を開きます（localhost は HTTPS でなくても WebXR が使えます）
