# ハマころ！ — ころがせ、ヨコハマ。まきこめ、せかい。

three.js で作った「転がして巻き込む」3D ゲーム。直径 30cm の玉で横浜の
**みなとみらい → 新港（赤レンガ倉庫）→ 山下公園 → 中華街** を転がり、
自分より小さいものを巻き込んで大きくなります。横浜をまるごと巻き込んだら関東平野へ、
そこから地球に飛び出して日本列島、最後は世界中を巻き込みます。

ジャンル（転がして巻き込む）の仕組みを使ったオリジナル作品です。
キャラクター・音楽・モデルはすべてこのリポジトリ内で作ったもの（音は Web Audio で合成）です。

## 遊び方

| 操作 | キーボード / マウス | スマホ |
|---|---|---|
| 前へ / うしろ | `W` `S` / `↑` `↓` | 画面左側をスティックとして上下 |
| 向きをかえる | `A` `D` / `←` `→`、マウスをドラッグ | スティック左右、右側をドラッグ |
| ダッシュ | `Space` / `Shift` | スティックをいっぱいに倒す |
| 音 / ポーズ | `M` / `P` | 右上のボタン |

玉を押すのはネクマックス、指令を出すのは **松井社長** です。社長はゲームの始めとステージの変わり目に空に大きく現れて指令を出し、
目標を達成するたびに次の指令をくれます（画面左上の吹き出し）。

### 巻き込む・乗り越える・ぶつかる

| 相手 | どうなるか |
|---|---|
| 玉の直径の約 7 割より小さいもの | 巻き込む |
| それより大きいが、高さが玉の半径の半分くらいまでの低いもの（ベンチ、田んぼ、空港など） | 上を転がって乗り越える（ぶつからない） |
| それより大きくて高いもの | 跳ね返される。「◯◯は 直径 ◯m から まきこめる」と表示 |

巻き込んだものを落とすのは、**強い衝撃のとき** だけです。衝撃は「近づく速さ（相手が動いていれば相手の速さも足す）÷ ふだんの最高速度」で決まり、
相手が大きいほど少し強くなります。
- ふだんの速さでぶつかるだけなら、何も落としません。
- ダッシュで大きな建物に激突したとき、走ってくるクルマや船にぶつかられたときに、外側の 1〜2 個を落とします。
- 落とすのは最近巻き込んだ小さめのもの（1 個で玉の 4% まで）で、大物は落としません。落としたあとの 2.5 秒は、続けて落としません。
- 何を落としたか、なぜ落としたか（「ダッシュで ◯◯に 激突！」など）が画面に出ます。

### ゲームモード

| モード | 内容 | 記録 |
|---|---|---|
| ストーリー | 横浜 → 関東 → 日本 → 世界。地球ごと巻き込むまで | クリア時間 |
| タイムアタック | 横浜で 5 分。どこまで大きくなれるか（300m でクリア） | 最大の直径 |
| おつかい | 松井社長に頼まれた 6 つの品物（シウマイ弁当、赤い靴、パンダのぬいぐるみ、獅子舞、人力車、中華街の門）を探して巻き込む | クリア時間 |
| ステージをえらぶ | 関東から（直径 300m）／日本から（直径 20km）始める | — |

記録はブラウザ（localStorage）に保存します。巻き込んだものは、右下のカードに 3D で名前・大きさと一緒に表示されます。

### ステージの流れ

| ステージ | 目標（直径） | 舞台・巻き込めるもの |
|---|---|---|
| 横浜 | 1m | 運河パーク：空き缶、シウマイ、ハト、カモメ |
| | 5m | 中華街・山下公園：人、屋台、自転車、獅子舞。5m で海に入れる |
| | 20m | 夕暮れ：クルマ、木、ボート |
| | 60m | 中華街のビル、家、お店 |
| | 150m | 夜景：オフィスビル、観覧車、赤レンガ倉庫、客船 |
| | 300m | ランドマークタワー、ベイブリッジ……ヨコハマをまるごと |
| 関東 | 1km | 夜明けの川崎：工場、電車、住宅街 |
| | 3km | 東京：東京タワー、スカイツリー、東京駅、渋谷 |
| | 8km | 羽田・成田空港、遊園地、関東平野 |
| | 20km | 筑波山・丹沢・箱根まで、関東をまるごと |
| 日本 | 100km | 地球に飛び出して日本列島へ：富士山、名古屋・大阪 |
| | 300km | 北海道から沖縄まで |
| 世界 | 1,000km → 3,000km → 4,000km | アジア、世界中、そして地球そのもの |

一度に巻き込める量には上限があり、建物が取れるようになった後も急に大きくなりすぎないようにしています（`js/main.js` の `CAP_CURVE`）。

## 動かし方

ビルド不要。静的ファイルとして配信するだけです（three.js は CDN から読み込みます）。

```bash
cd yokohama-roll
python3 -m http.server 8765
# → http://localhost:8765/
```

URL パラメータ（デバッグ用）: `?r=20`（最初から半径 20m）、`?stage=kanto` / `?stage=world`（関東・地球ステージから）、
`?auto`（自動操縦）、`?debug`（ログ）、`?lowres`（低解像度）。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | HUD・タイトル・リザルト画面、import map |
| `js/main.js` | ゲームループ、玉の物理、カメラ、入力、HUD、ステージ遷移 |
| `js/map.js` | 横浜の地図（圧縮した配置）：陸地、道路、エリア、ランドマーク配置 |
| `js/engine/town.js` | 横浜ステージの生成（地面・海・建物・ばらまき・車や人の動き） |
| `js/kanto_map.js`, `js/engine/kanto.js` | 関東ステージ（地図・海岸線・路線、描いた地面、街区・工場・電車・船・飛行機） |
| `js/engine/globe.js` | 地球ステージ（半径 1000 の地球、日本の高解像度マップ、世界の名所） |
| `js/engine/objects.js` | モデル登録、InstancedMesh 描画、距離カリング、当たり判定 |
| `js/engine/minimap.js` | ミニマップ |
| `js/geo.js` | ローポリ モデリング用の小さな部品キット |
| `js/models/*.js` | モデル：`town_small`（小物）、`town_mid`（車・木・屋台）、`town_big`（ランドマーク・ビル）、`kanto`（関東の街区・東京の名所・山）、`world`（日本と世界の名所、地球のテクスチャ） |
| `js/audio.js` | Web Audio で合成する BGM と効果音 |
| `tools/preview.mjs` | モデル一覧を PNG に描き出す（`node tools/preview.mjs models/town_big.js out.png`） |
| `tools/play.mjs` | ヘッドレスでゲームを起動してスクリーンショット |

開発用ツールを使うときだけ `npm install`（three を node_modules に入れる）が必要です。
