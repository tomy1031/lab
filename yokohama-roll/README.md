# ハマころ！ — ころがせ、ヨコハマ。まきこめ、せかい。

three.js で作った「転がして巻き込む」3D ゲーム。直径 30cm の玉で横浜の
**みなとみらい → 新港（赤レンガ倉庫）→ 山下公園 → 中華街** を転がり、
自分より小さいものを巻き込んで大きくなります。横浜をまるごと巻き込んだら関東平野へ、
そこから地球に飛び出して日本列島、最後は世界中を巻き込みます。

ジャンル（転がして巻き込む）の仕組みを使ったオリジナル作品です。
キャラクター・音楽・モデルはすべてこのリポジトリ内で作ったもの（音は Web Audio で合成）です。

## 遊び方

| 操作 | キーボード / マウス | スマホ |
|---|---|---|
| 前へ / うしろ | `W` `S` / `↑` `↓` | 画面左側をスティックとして上下 |
| 向きをかえる | `A` `D` / `←` `→`、マウスをドラッグ | スティック左右、右側をドラッグ |
| ダッシュ | `Space` / `Shift` | スティックをいっぱいに倒す |
| 音 / ポーズ | `M` / `P` | 右上のボタン |

玉を押すのはネクマックス、指令を出すのは **松井社長** です。社長はゲームの始めとステージの変わり目に空に大きく現れて指令を出し、
目標を達成するたびに次の指令をくれます（画面左上の吹き出し）。

### 巻き込む・乗り越える・ぶつかる

| 相手 | どうなるか |
|---|---|
| 玉の直径の約 7 割より小さいもの | 巻き込む |
| それより大きいが、高さが玉の半径（車軸の高さ）までのもの（ベンチ、花壇、低い建物など） | 上を転がって乗り越える |
| 平たいもの（高さが幅の 3 割以下：田んぼ、広場、空港など）で、高さが半径の 1.4 倍まで | 上を転がって乗り越える |
| それより大きくて高いもの | 跳ね返される。「◯◯は 直径 ◯m から まきこめる」と表示 |

玉には少しだけ引力があります。玉の大きさの 6 割より小さい物は、玉の中心から半径の 1.5 倍以内にあると、ゆっくり玉のほうへ寄ってきます。
小さい物ほど少し離れていても巻き込めます（いちばん小さい物で半径の 1.19 倍まで）。巻き込んだビルのすきまに、小さい物が入り込んで取れなくなることはありません。
走っているクルマ・電車・船・飛行機は寄ってきません。

止まっている物にぶつかっても、どんなに速くても **何も落としません**。
落とすのは、走ってくるクルマ・電車・船などに **ぶつけられたとき** だけです（相手が自分のふだんの最高速度の 6 割以上の速さで向かってきたとき）。
- 落とすのは外側の 1〜2 個で、大物は落としません。
- 落としたあとの 3 秒は、続けて落としません。
- 落としたものは近くに転がるので、また拾えます。

スマホでは、画面の右下あたりの赤いボタンを押しているあいだダッシュします（スティックを倒しきってもダッシュしません）。

## ゲームモード

| モード | 内容 | 記録 |
|---|---|---|
| ストーリー | 横浜 → 関東 → 日本 → 世界。地球ごと巻き込むまで | クリア時間 |
| タイムアタック | 横浜で 5 分。どこまで大きくなれるか（300m でクリア） | 最大の直径 |
| おつかい | 松井社長に頼まれた 6 つの品物（シウマイ弁当、赤い靴、パンダのぬいぐるみ、獅子舞、人力車、中華街の門）を探して巻き込む | クリア時間 |
| ステージをえらぶ | 関東から（直径 300m）／日本から（直径 20km）始める | — |

記録はブラウザ（localStorage）に保存します。巻き込んだものは、右下のカードに 3D で名前・大きさと一緒に表示されます。

### ステージの流れ

| ステージ | 目標（直径） | 舞台・巻き込めるもの |
|---|---|---|
| 横浜 | 1m | 運河パーク：空き缶、シウマイ、ハト、カモメ |
| | 5m | 中華街・山下公園：人、屋台、自転車、獅子舞。5m で海に入れる |
| | 20m | 夕暮れ：クルマ、木、ボート |
| | 60m | 中華街のビル、家、お店 |
| | 150m | 夜景：オフィスビル、観覧車、赤レンガ倉庫、客船 |
| | 300m | ランドマークタワー、ベイブリッジ……ヨコハマをまるごと |
| 関東 | 1km | 夜明けの川崎：工場、電車、住宅街 |
| | 3km | 東京：東京タワー、スカイツリー、東京駅、渋谷 |
| | 8km | 羽田・成田空港、遊園地、関東平野 |
| | 20km | 筑波山・丹沢・箱根まで、関東をまるごと |
| 日本 | 100km | 地球に飛び出して日本列島へ：富士山、名古屋・大阪 |
| | 300km | 北海道から沖縄まで |
| 世界 | 1,000km → 3,000km → 4,000km | アジア、世界中、そして地球そのもの |

一度に巻き込める量には上限があり、建物が取れるようになった後も急に大きくなりすぎないようにしています（`js/main.js` の `CAP_CURVE`）。

## 画質と軽さ（古いスマホ向け）

端末に合わせて、画質を **高・中・低** から自動で選びます（タイトル画面の「画質」ボタンで変えられます。選んだ画質は記憶します）。

| | 高（パソコン） | 中（スマホ） | 低（古いスマホ・メモリ 4GB 以下など） |
|---|---|---|---|
| 解像度 | 1.75 倍まで | 1.25 倍まで | 0.85 倍 |
| 影 | あり | あり（粗め） | なし |
| 街の小物の数 | 100% | 80% | 60% |
| 遠くの建物を簡単な形にする距離 | 大きさの 32 倍より遠く | 22 倍 | 14 倍 |

- **小物が少なくても、ゲームの長さは同じです。** 小物が少ない画質では、1 個を巻き込んだときに大きくなる量を、その分だけ増やしています。
- 遊んでいるあいだ 3 秒ごとにフレーム数を測り、28fps を下回ると解像度を少しずつ下げます（一度だけ「画質を下げました」と出ます）。なめらかに動くと元に戻します。

どの画質でも、次のようにして描く量と計算を減らしています（`js/engine/objects.js`）。
- 霧で見えなくなる距離より遠くの物は描きません。
- カメラの後ろや横の物は描きません。ただし、影が見える玉のまわりの物は描きます。
- 地球ステージでは、地平線の向こう（地球の裏側）の物を描きません。
- 遠くの建物は、形を簡単にしたモデルで描きます（三角形が 1/5〜1/20）。夜の窓の明かりは、壁全体のほのかな光に置き換えます。
  クレーンや観覧車のように、簡単にすると形が崩れる物はそのままです。
- 止まっている物の描画リストは、4 フレームに 1 回ずつ順番に作り直します。物が動いたとき・巻き込んだとき・カメラが大きく向きを変えたときは、すぐに作り直します。
- 玉から遠い人や車は、4 フレームに 1 回まとめて動かします。
- 当たり判定は、玉の近くのマス目にある物だけを調べます。

横浜のはじめの場面で 1 フレームに描く三角形の数は、低画質で約 137 万 → 約 19 万、直径 240m の夜景で約 104 万 → 約 16 万になりました（高画質では約 470 万 → 約 100 万）。
動き・当たり判定などの計算は、1 フレーム 5.8ms → 1.7ms（開発用パソコンで測定）です。

## VR モード（Meta Quest など）

WebXR に対応したブラウザ（Quest ブラウザなど）で開くと、タイトルに「🥽 VR で あそぶ」が出ます。オンにしてモードを選ぶと、そのまま VR で始まります。
遊んでいる途中は、右上の 🥽 ボタンで出入りできます。VR は同じゲームを別の見方で表示しているだけなので、街・モデル・ルール・社長のセリフを変えれば VR にもそのまま反映されます（`js/vr.js`）。

| 操作 | 快適モード（標準） | ふつう |
|---|---|---|
| 左スティック 上下 | 前へ／うしろ | 同じ |
| 左スティック 左右 | 玉を横に転がす（視界は回らない） | ゆっくり向きを変える |
| 右スティック 左右 | 30° ずつ向きを変える（スナップ） | 同じ |
| トリガー／グリップ | ダッシュ（0.4 秒かけて加速） | ダッシュ |
| B／Y | 快適 ⇄ ふつう の切り替え（記憶します） | 同じ |
| スティックを押し込む | 視点をまっすぐに戻す | 同じ |

酔いにくくするために、次のようにしています。
- 地平線はいつも水平です。
- 快適モードでは、視界がなめらかに回ることはありません。最高速も 0.8 倍です。
- 動いているあいだだけ、視界の周りを暗くします（中央 68° は隠しません）。
- 低いものを乗り越えたときの上下の揺れは、ほぼ打ち消します。
- ステージの切り替えは白くフェードします。
- 玉は、どの大きさでも目の前で直径 80cm に見えるよう、世界の縮尺を合わせています。
- 情報パネルは視線の少し下に置いています。

VR 中は影を切り、描画距離を 0.6 倍にしています。VR 対応端末では街の物の数も 6 割にしています。
テストは Meta の WebXR エミュレーター（IWER）で Quest 3 をまねて行っています（`node tools/vr_test.mjs <出力フォルダ>`）。実機での速さはまだ測っていません。

## アプリとして入れる・更新（PWA）

公開版（https://tomy1031.github.io/lab/yokohama-roll/ ）は、スマホやパソコンに「ホーム画面に追加」「アプリをインストール」で入れられます。一度開けばオフラインでも遊べます。

古い版が残らないようにしています。
- **公開の仕組み:** 公開するたびに、ゲームのコードを `v/<内容のハッシュ>/` という新しいフォルダに置きます（`site/build.mjs`）。ブラウザが古いコードを使い続けることはありません。
- **ページの取得:** ページ（index.html）と `version.json` は、毎回ネットから取りに行きます（service worker `sw.js`）。読み込み直せば、いつも最新版になります。
- **開いたままの場合:** ゲームを開いたまま新しい版が公開されたときは、`version.json` で気づきます。チェックするのは、起動時、10 分ごと、アプリに戻ったときです。
  - タイトル画面か結果画面なら、そのまま新しい版に切り替わります。
  - 遊んでいる途中なら「新しいバージョンがあります［更新する］」と出ます。
- **古いページが残っていた場合:** 古いページがキャッシュに残っていて、もう無いフォルダを指していたときは、自動でページを取り直します。

確認は `SKIP_AIC=1 node site/build.mjs <出力フォルダ>` のあと `node yokohama-roll/tools/pwa_test.mjs <出力フォルダ>` で行います。このテストでは、新しい版への自動切り替えとオフライン起動を見ています。

## 動かし方

ビルド不要。静的ファイルとして配信するだけです（three.js は CDN から読み込みます）。

```bash
cd yokohama-roll
python3 -m http.server 8765
# → http://localhost:8765/
```

URL パラメータ（デバッグ用）: `?r=20`（最初から半径 20m）、`?stage=kanto` / `?stage=world`（関東・地球ステージから）、
`?auto`（自動操縦）、`?debug`（ログ）、`?lowres`（低解像度）、`?quality=high|mid|low`（画質）、`?lod=0`（遠くの建物を簡単にしない）。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | HUD・タイトル・リザルト画面、import map |
| `js/main.js` | ゲームループ、玉の物理、カメラ、入力、HUD、ステージ遷移 |
| `js/map.js` | 横浜の地図（圧縮した配置）：陸地、道路、エリア、ランドマーク配置 |
| `js/engine/town.js` | 横浜ステージの生成（地面・海・建物・ばらまき・車や人の動き） |
| `js/kanto_map.js`, `js/engine/kanto.js` | 関東ステージ（地図・海岸線・路線、描いた地面、街区・工場・電車・船・飛行機） |
| `js/engine/globe.js` | 地球ステージ（半径 1000 の地球、日本の高解像度マップ、世界の名所） |
| `js/engine/objects.js` | モデル登録、InstancedMesh 描画、カリング（霧・視野・地平線）、遠くのモデルの簡略化、当たり判定 |
| `js/quality.js` | 画質の設定（高・中・低）、端末からの自動選択、フレームレートの見張り |
| `js/engine/minimap.js` | ミニマップ |
| `js/geo.js` | ローポリ モデリング用の小さな部品キット |
| `js/models/*.js` | モデル：`town_small`（小物）、`town_mid`（車・木・屋台）、`town_big`（ランドマーク・ビル）、`kanto`（関東の街区・東京の名所・山）、`world`（日本と世界の名所、地球のテクスチャ） |
| `js/audio.js` | Web Audio で合成する BGM と効果音 |
| `tools/preview.mjs` | モデル一覧を PNG に描き出す（`node tools/preview.mjs models/town_big.js out.png`） |
| `tools/play.mjs` | ヘッドレスでゲームを起動してスクリーンショット |

開発用ツールを使うときだけ `npm install`（three を node_modules に入れる）が必要です。
