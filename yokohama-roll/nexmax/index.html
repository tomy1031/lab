ファイルの中身

形式glTF 2.0 バイナリ（.glb）。テクスチャも動きも 1 ファイルに入っています。Khronos の glTF Validator でエラー・警告なし
大きさ・向き身長 1.2 m（1 単位 = 1 m）。足もとが原点、正面が +Z、上が +Y
ポリゴン約 3.4 万三角形（りんかく線を含む）
関節hips torso head eyes shoulderL/R elbowL/R wristL/R hipL/R kneeL/R ankleL/R（＋全体の body）。部品ごとに関節の下にぶら下がる「かたい」作りで、スキニングはありません。こぶしの先に取り付け用の nmclawMuzzle
モーションidle（待機）・walk・run・dash・wave・sit はループ、jump・punch・punchL・hurt は立ち姿から始まって立ち姿にもどる 1 回分。30fps
表情happy・determined・worried・surprised。目と口は表情ごとの部品（eyeballs_*・features_*）で、見せない表情は大きさ 0。face_* のクリップで切りかえられます
手開いた手とこぶし（handR_open・handR_fist など）。パンチやダッシュのクリップで自動で切りかわります
材質ビニールのような PBR（sheen・clearcoat 付き）、胸のロゴはテクスチャ。りんかく線は光の影響を受けない紺色

使い方

  • Blender：ファイル → インポート → glTF 2.0。動きは「アクション」として入っているので、ドープシート（アクションエディター）で選びます。りんかく線を出すには、outline マテリアルの設定で「裏面を非表示（Backface Culling）」がオンになっていることを確認してください（EEVEE）
  • Unity：glTFast か UnityGLTF のパッケージを入れて、ファイルを Assets にドラッグ。クリップはアニメーションとして読み込まれます
  • Unreal Engine：glTF Importer（標準プラグイン）で読み込み
  • Windows：「3D ビューアー」でそのまま開けます。ウェブなら three.js の GLTFLoader や <model-viewer> で表示できます
  • りんかく線がいらないときは、名前が _outline で終わる部品を消すか隠してください
  • 表情を手で変えるときは、使いたい eyeballs_* と features_* の大きさを 1、ほかを 0 にします（face_* クリップと同じこと）

ゲームの中ではりんかく線の太さを画面に合わせて変え、影の部分を少し明るくしています。ファイルではりんかく線の太さは一定（4.5 mm）で、影はソフトの照明しだいです。ゲームに出てくる腕のクロー（NMClaw）は入っていません。

モデル：ネクマックス（tomy1031/nexmax_chronicle、ハマころ！で使っているものと同じ）。ファイルはゲームのモデルから tools/export-nexmax.mjs で作っています。利用条件（改変・再配布・商用利用）はまだ決まっていません。
